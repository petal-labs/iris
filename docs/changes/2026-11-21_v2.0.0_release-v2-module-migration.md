## Summary

Prepares Iris `v2.0.0` for release by migrating the Go module path from `github.com/petal-labs/iris` to `github.com/petal-labs/iris/v2` across the entire repository, promoting all changes since `v1.0.0` in `CHANGELOG.md` into `## [2.0.0] - 2026-11-21`, and updating `scaffoldSDKVersionFallback`, build linker flags, release workflow, and documentation to `v2.0.0`.

## Motivation

Iris `v2.0.0` ships major new speech and real-time voice agent capabilities (`providers/elevenlabs`, `voice`, `core` speech/voice contracts) alongside breaking removals of deprecated and retired `core.ModelID` constants across provider catalogs (#138, #183). Under Go semantic import versioning, releasing `v2.0.0` requires the root module path to carry the `/v2` major version suffix (`github.com/petal-labs/iris/v2`).

## What Changed

### New Additions

- `CHANGELOG.md`: added the dated `## [2.0.0] - 2026-11-21` release section consolidating all features and breaking changes since `v1.0.0`, along with the updated `[2.0.0]` and `[Unreleased]` compare links.

### Modifications

- **`go.mod`**: updated module declaration from `github.com/petal-labs/iris` to `github.com/petal-labs/iris/v2`.
- **`contrib/otel/go.mod` & `examples/go.mod`**: updated `require` and `replace` directives to `github.com/petal-labs/iris/v2 v2.0.0`. Both submodules keep their own module paths (`github.com/petal-labs/iris/contrib/otel` and `github.com/petal-labs/iris/examples`).
- **All internal Go imports (315 `.go` files)**: updated `github.com/petal-labs/iris/<pkg>` imports and package doc references to `github.com/petal-labs/iris/v2/<pkg>` (preserving `contrib/otel`'s OpenTelemetry `TracerName` `"github.com/petal-labs/iris"` and GitHub web URLs).
- **`.github/workflows/release.yml` & `Makefile`**: updated linker-flag package paths (`PKG="github.com/petal-labs/iris/v2/cli/commands"` and `LDFLAGS`) so release binaries embed `Version`, `Commit`, and `BuildDate` accurately.
- **`.golangci.yml`**: updated `goimports.local-prefixes` to `github.com/petal-labs/iris/v2`.
- **`cli/commands/init.go` & `cli/commands/init_test.go`**: updated `scaffoldSDKVersionFallback` to `"v2.0.0"` and updated generated `go.mod` / `main.go` templates to import and require `github.com/petal-labs/iris/v2`.
- **Documentation (`README.md`, `docs/*.md`, `docs/guides/*.md`)**: updated `go get`, `go install`, pkg.go.dev badge, Cosign verification tag example (`v2.0.0`), and Go import snippets to `github.com/petal-labs/iris/v2`.

## Usage Examples

### Example: Importing Iris v2

```go
package main

import (
	"context"
	"fmt"
	"os"

	"github.com/petal-labs/iris/v2/core"
	"github.com/petal-labs/iris/v2/providers/openai"
)

func main() {
	client := core.NewClient(openai.New(os.Getenv("OPENAI_API_KEY")))
	resp, err := client.Chat(openai.ModelGPT62Astra).
		User("Hello from Iris v2!").
		GetResponse(context.Background())
	if err != nil {
		fmt.Fprintln(os.Stderr, "Error:", err)
		os.Exit(1)
	}
	fmt.Println(resp.Output)
}
```


## Integration Notes

- Downstream repositories (`petalflow`, `cortex`, etc.) must update their `go.mod` dependency and Go import paths from `github.com/petal-labs/iris` to `github.com/petal-labs/iris/v2` when upgrading to `v2.0.0`.
- `contrib/otel` retains its `TracerName` default (`"github.com/petal-labs/iris"`) so existing OpenTelemetry dashboards and trace filters do not break on upgrade.
- Pushing the annotated `v2.0.0` tag after this PR merges will trigger `.github/workflows/release.yml`, producing cross-compiled binaries, SPDX SBOM (`iris-v2.0.0.spdx.json`), `checksums.txt`, and Cosign keyless `.sig` bundles.

## Breaking Changes & Migration

- **Go module path**: update `go.mod` (`go get github.com/petal-labs/iris/v2@v2.0.0`) and replace imports `github.com/petal-labs/iris/...` with `github.com/petal-labs/iris/v2/...` (excluding `github.com/petal-labs/iris/contrib/otel`).
- **Removed deprecated model constants**: see `CHANGELOG.md` `[2.0.0]` and `docs/changes/2026-11-21_v0.0.0-dev_provider-model-catalog-refresh.md` for replacement constants.

## Deferred / Out of Scope

- Tagging `contrib/otel` independently is not part of this root `v2.0.0` release.
