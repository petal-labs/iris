## Summary

Creates the authoritative PetalFlow Voice Integration Specification in
`docs/guides/petalflow-voice-integration.md` (with executable Go contract tests
in `voice/petalflow_contract_test.go`) documenting typed node/tool ports,
session execution boundaries, credential hydration, cross-repository
dependency gates, and integration acceptance gates for Issue #160
(`IRIS-VOICE-017`).

## Motivation

Downstream PetalFlow (`#249`–`#254`) and Cortex (`#76`–`#80`) implementation
issues require an unambiguous, code-verified contract specifying how PetalFlow
nodes and session runners bind to Iris's concrete `core`, `providers/elevenlabs`,
`voice`, and `contrib/otel` APIs without conflating Iris-managed pipelines,
Speech Engine upstream servers, and hosted ElevenAgents.

## What Changed

### New Additions

- **`docs/guides/petalflow-voice-integration.md`**:
  - Architecture & responsibility partition across Iris, PetalFlow, Cortex, and
    Edge/Application audio I/O (with Mermaid data/control-flow diagram).
  - Typed port mappings for:
    - Transcription Node (`petalflow#249` -> `core.TranscriptionRequest` / `core.TranscriptionResponse`, Scribe limits, reader non-retry rule).
    - Synthesis Node (`petalflow#250` -> `core.SpeechRequest` / `core.SpeechResponse` / `core.SpeechStream` / `core.DrainSpeechStream`).
    - Voice session tool ports (`petalflow#253` -> `voice.RegistryToolExecutor`, direct `tools.Tool`, and external schema-only `core.Tool` + `VoiceEventToolCall` / `SubmitToolResult`).
  - Session boundary and explicit mode distinction (`iris_pipeline` vs.
    `speech_engine` vs. `elevenagents`), partial vs. committed transcript
    hygiene, `core.VoiceTurnTracker` stale-audio suppression, bounded channels,
    and deterministic `Close()` cleanup.
  - Credential & provider hydration rules (`petalflow#251`), `core.Secret`
    wrapping, private ElevenAgents signed-URL minting (`GetAgentSignedURL`),
    and model compatibility preflight (`FeatureSpeechSynthesisRealtime`).
  - Cross-repository dependency status matrix (`petalflow#249`–`#254`,
    `cortex#76`–`#80`), five mandatory integration acceptance gates, and known
    limitations.
- **`voice/petalflow_contract_test.go`**:
  - Executable Go contract tests (`TestPetalFlowIntegrationContracts`) verifying
    capability discovery (`AsSpeechSynthesizer`, `AsSpeechRecognizer`,
    `AsRealtimeSpeechRecognizer`, `AsRealtimeSpeechSynthesizer`,
    `AsVoiceSessionProvider`), `eleven_v3` WS TTS preflight rejection, API key
    redaction, external tool-port dispatch via `SubmitToolResult`,
    `VoiceTurnTracker.ShouldPlayAudio` filtering, and committed-only utterance
    filtering under `-race`.

### Modifications

- **`docs/README.md`** and **`docs/guides/speech.md`**: Linked the new
  PetalFlow Voice Integration Specification and refreshed the Speech Guide
  summary entry.
