## Summary

Adds provider-agnostic audio and speech data types, validation, streaming helpers,
and JSON serialization contracts to `github.com/petal-labs/iris/core` for Issue #144
(`IRIS-VOICE-001`). This establishes the foundational audio payload, text-to-speech,
and speech-to-text request/response models required by upcoming speech provider
interfaces (`#145`), the ElevenLabs provider (`#146`–`#158`), PetalFlow speech nodes,
and Cortex transcript ingestion without modifying any existing provider.

## Motivation

Iris previously deferred audio and speech contracts until after v1.0 because audio
operations require dedicated binary payload, format metadata, streaming chunk, and
transcription alignment models. Defining these types in `core` first gives all future
voice providers (ElevenLabs, OpenAI, and telephony integrations) a shared,
provider-independent contract while keeping `core.Provider` completely unchanged.

## What Changed

### New Additions

- **`core/audio.go`**:
  - Sentinel errors: `ErrInvalidAudioFormat`, `ErrInvalidAudioData`, `ErrInvalidAudioChunk`,
    `ErrInvalidSpeechRequest`, `ErrInvalidTranscriptionRequest`,
    `ErrInvalidTranscriptionResponse`, `ErrNilSpeechStream`.
  - Encoding & format types: `AudioEncoding` (`mp3`, `pcm`, `wav`, `opus`, `ogg`,
    `flac`, `aac`, `webm`, `ulaw`, `alaw`) with `IsValid()`, `MIMEType()`, and
    `FileExtension()`; structured `AudioFormat` with `IsZero()`, `IsValid()`,
    `Validate()`, `EffectiveMIMEType()`, `String()`, and 12 common format presets
    (`AudioFormatMP3_22050_32`, `AudioFormatMP3_44100_64`, `AudioFormatMP3_44100_128`,
    `AudioFormatMP3_44100_192`, `AudioFormatPCM16000`, `AudioFormatPCM22050`,
    `AudioFormatPCM24000`, `AudioFormatPCM44100`, `AudioFormatULaw8000`,
    `AudioFormatALaw8000`, `AudioFormatOpus48000_64`, `AudioFormatWAV16000`).
  - Payload & streaming types: `AudioData` (`IsEmpty`, `GetBytes`, `Validate`,
    privacy-safe `String`/`GoString`), `AudioChunk` (`Validate`, privacy-safe
    `String`/`GoString`), `SpeechStream` (3-channel streaming struct matching
    `ChatStream`/`ImageStream`), and `DrainSpeechStream(ctx, s)`.
  - Text-to-speech types: `VoiceSettings`, `SpeechRequest`, `SpeechUsage`,
    `SpeechResponse` with `Validate()` and privacy-safe `String`/`GoString`.
  - Speech-to-text types: `TranscriptionTimestampGranularity` (`""`, `"word"`,
    `"segment"`, `"character"`), `TranscriptionRequest`, `TranscriptionWord`,
    `TranscriptionSegment`, `AudioEvent`, `TranscriptionUsage`,
    `TranscriptionResponse` (including `IsFinal` committed-utterance flag) with
    `Validate()` and privacy-safe `String`/`GoString`.
- **`core/audio_test.go`**: Unit tests covering validation (success and failure),
  JSON round-trip serialization, `DrainSpeechStream` chunk accumulation, late error
  propagation, nil/partial channels, context cancellation/timeout, and privacy-safe
  `String`/`GoString` formatting.

### Modifications

- **`core/doc.go`**: Added `# Audio and Speech` package documentation summarizing
  the new types, streaming behavior, privacy-safe formatting, and limitations.

## Technical Specification

### Data Schemas / Types

```go
type AudioEncoding string

type AudioFormat struct {
	Encoding   AudioEncoding `json:"encoding"`
	SampleRate int           `json:"sample_rate,omitempty"`
	BitRate    int           `json:"bit_rate,omitempty"`
	Channels   int           `json:"channels,omitempty"`
	MIMEType   string        `json:"mime_type,omitempty"`
}

type AudioData struct {
	Data     []byte        `json:"data,omitempty"`
	Base64   string        `json:"base64,omitempty"`
	Format   AudioFormat   `json:"format"`
	Duration time.Duration `json:"duration_ns,omitempty"`
	Filename string        `json:"filename,omitempty"`
}

type AudioChunk struct {
	Data      []byte        `json:"data,omitempty"`
	Format    AudioFormat   `json:"format,omitempty"`
	Sequence  int64         `json:"sequence"`
	Timestamp time.Duration `json:"timestamp_ns,omitempty"`
	Duration  time.Duration `json:"duration_ns,omitempty"`
	IsFinal   bool          `json:"is_final,omitempty"`
}

type VoiceSettings struct {
	Speed           *float64 `json:"speed,omitempty"`
	Stability       *float64 `json:"stability,omitempty"`
	SimilarityBoost *float64 `json:"similarity_boost,omitempty"`
	Style           *float64 `json:"style,omitempty"`
	UseSpeakerBoost *bool    `json:"use_speaker_boost,omitempty"`
}

type SpeechRequest struct {
	Model         ModelID           `json:"model,omitempty"`
	VoiceID       string            `json:"voice_id"`
	Text          string            `json:"text"`
	Format        AudioFormat       `json:"format,omitempty"`
	Language      string            `json:"language,omitempty"`
	VoiceSettings *VoiceSettings    `json:"voice_settings,omitempty"`
	Seed          *int64            `json:"seed,omitempty"`
	PreviousText  string            `json:"previous_text,omitempty"`
	NextText      string            `json:"next_text,omitempty"`
	RequestID     string            `json:"request_id,omitempty"`
	Metadata      map[string]string `json:"metadata,omitempty"`
}

type SpeechUsage struct {
	InputCharacters int           `json:"input_characters,omitempty"`
	AudioDuration   time.Duration `json:"audio_duration_ns,omitempty"`
	OutputBytes     int64         `json:"output_bytes,omitempty"`
}

type SpeechResponse struct {
	ID      string      `json:"id,omitempty"`
	Model   ModelID     `json:"model,omitempty"`
	VoiceID string      `json:"voice_id,omitempty"`
	Audio   AudioData   `json:"audio"`
	Usage   SpeechUsage `json:"usage,omitempty"`
}

type SpeechStream struct {
	Ch    <-chan AudioChunk
	Err   <-chan error
	Final <-chan *SpeechResponse
}

type TranscriptionTimestampGranularity string

type TranscriptionRequest struct {
	Model          ModelID                           `json:"model,omitempty"`
	Audio          *AudioData                        `json:"audio,omitempty"`
	Reader         io.Reader                         `json:"-"`
	Format         AudioFormat                       `json:"format,omitempty"`
	Filename       string                            `json:"filename,omitempty"`
	Language       string                            `json:"language,omitempty"`
	Prompt         string                            `json:"prompt,omitempty"`
	Keyterms       []string                          `json:"keyterms,omitempty"`
	Diarize        bool                              `json:"diarize,omitempty"`
	NumSpeakers    *int                              `json:"num_speakers,omitempty"`
	Timestamps     TranscriptionTimestampGranularity `json:"timestamps,omitempty"`
	TagAudioEvents bool                              `json:"tag_audio_events,omitempty"`
	Temperature    *float64                          `json:"temperature,omitempty"`
	MaxBytes       int64                             `json:"max_bytes,omitempty"`
	RequestID      string                            `json:"request_id,omitempty"`
	Metadata       map[string]string                 `json:"metadata,omitempty"`
}

type TranscriptionWord struct {
	Text       string        `json:"text"`
	Start      time.Duration `json:"start_ns"`
	End        time.Duration `json:"end_ns"`
	Type       string        `json:"type,omitempty"`
	SpeakerID  string        `json:"speaker_id,omitempty"`
	Confidence *float64      `json:"confidence,omitempty"`
	LogProb    *float64      `json:"logprob,omitempty"`
}

type TranscriptionSegment struct {
	ID         int                 `json:"id,omitempty"`
	Text       string              `json:"text"`
	Start      time.Duration       `json:"start_ns"`
	End        time.Duration       `json:"end_ns"`
	SpeakerID  string              `json:"speaker_id,omitempty"`
	Words      []TranscriptionWord `json:"words,omitempty"`
	Confidence *float64            `json:"confidence,omitempty"`
}

type AudioEvent struct {
	Type       string        `json:"type"`
	Start      time.Duration `json:"start_ns,omitempty"`
	End        time.Duration `json:"end_ns,omitempty"`
	SpeakerID  string        `json:"speaker_id,omitempty"`
	Confidence *float64      `json:"confidence,omitempty"`
}

type TranscriptionUsage struct {
	AudioDuration time.Duration `json:"audio_duration_ns,omitempty"`
	InputBytes    int64         `json:"input_bytes,omitempty"`
}

type TranscriptionResponse struct {
	ID                  string                 `json:"id,omitempty"`
	Model               ModelID                `json:"model,omitempty"`
	Text                string                 `json:"text"`
	Language            string                 `json:"language,omitempty"`
	LanguageProbability *float64               `json:"language_probability,omitempty"`
	Duration            time.Duration          `json:"duration_ns,omitempty"`
	Words               []TranscriptionWord    `json:"words,omitempty"`
	Segments            []TranscriptionSegment `json:"segments,omitempty"`
	AudioEvents         []AudioEvent           `json:"audio_events,omitempty"`
	IsFinal             bool                   `json:"is_final,omitempty"`
	Usage               TranscriptionUsage     `json:"usage,omitempty"`
}
```

### Go Package API

- `func DrainSpeechStream(ctx context.Context, s *SpeechStream) (*SpeechResponse, error)` —
  accumulates streamed `AudioChunk` payloads until completion or context cancellation,
  preserving late errors and preferring concrete provider errors over `ctx.Err()`.
- Validation methods (`AudioFormat.Validate`, `AudioData.Validate`, `AudioChunk.Validate`,
  `VoiceSettings.Validate`, `SpeechRequest.Validate`, `TranscriptionRequest.Validate`,
  `TranscriptionWord.Validate`, `TranscriptionSegment.Validate`, `AudioEvent.Validate`,
  `TranscriptionResponse.Validate`) return errors wrapping their corresponding sentinel
  errors for `errors.Is` inspection.
- `String()` and `GoString()` on audio payload, request, and response types omit raw
  audio bytes, prompts, and transcript text by default to satisfy privacy requirements.

## Usage Examples

### Example: Validating a Speech Request and Draining a Speech Stream

```go
req := &core.SpeechRequest{
	Model:   "eleven_flash_v2_5",
	VoiceID: "voice_123",
	Text:    "Hello from Iris.",
	Format:  core.AudioFormatMP3_44100_128,
}
if err := req.Validate(); err != nil {
	return err
}

// Given a *core.SpeechStream returned by a streaming synthesizer:
resp, err := core.DrainSpeechStream(ctx, stream)
if err != nil {
	return err
}
audioBytes, err := resp.Audio.GetBytes()
```

### Example: Validating a Transcription Request (Error Case)

```go
req := &core.TranscriptionRequest{
	Model:    "scribe_v2",
	Audio:    &core.AudioData{Data: rawWAV, Format: core.AudioFormatWAV16000},
	MaxBytes: 1024,
}
if err := req.Validate(); errors.Is(err, core.ErrInvalidTranscriptionRequest) {
	// Handle oversized or malformed transcription input before calling a provider.
}
```

## Breaking Changes & Migration

None. All additions are backwards-compatible new exports in `package core`.

## Deferred / Out of Scope

- Optional speech capability interfaces (`SpeechSynthesizer`, `SpeechRecognizer`)
  and `Feature` discovery constants — deferred to Issue `#145` (`IRIS-VOICE-002`).
- Real-time voice session and event contracts (`VoiceSession`, `VoiceEvent`) —
  deferred to Issue `#155` (`IRIS-VOICE-012`).
- ElevenLabs provider configuration, TTS, and Scribe STT implementations — deferred
  to Issues `#146`–`#154`.
- Hardware audio capture and playback — explicitly out of scope for Iris (handled
  by host applications).
