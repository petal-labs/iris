## Summary

Researched ElevenLabs' official Speech Engine upstream protocol and implemented
a Go-native, zero-extra-dependency `SpeechEngineHandler` (`http.Handler`) and
HS256 JWT verifier (`VerifySpeechEngineJWT`) in `providers/elevenlabs` for
Issue #157 (`IRIS-VOICE-014`).

## Motivation

ElevenLabs Speech Engine is distinct from both client-initiated STT/TTS
pipelines (`voice.Pipeline`) and hosted ElevenAgents:
- **Protocol validation finding**: ElevenLabs officially documents the
  *Speech Engine Upstream* WebSocket protocol
  (`https://elevenlabs.io/docs/api-reference/speech-engine/speech-engine-upstream`),
  which is an **inverted WebSocket server protocol**. ElevenLabs acts as the
  WebSocket client, connects outbound to a developer-hosted `wsUrl` carrying an
  `X-Elevenlabs-Speech-Engine-Authorization` HS256 JWT (signed with the SHA-256
  hash of the ElevenLabs API key, `iss: https://api.elevenlabs.io/convai/speech-engine`,
  `sub: convai_speech_engine_upstream`, 60s clock-skew leeway), sends `init`,
  `user_transcript` (with monotonic `event_id` and cumulative conversation
  history), `ping`, and `close` messages, and synthesizes streamed
  `agent_response` frames (`type`, `event_id`, `content`, `is_final`) returned
  by the developer's LLM server.
- Because the wire protocol is standard JSON-over-WebSocket + HS256 JWT, a
  clean Go `http.Handler` adapter is directly feasible using `crypto/hmac`,
  `crypto/sha256`, and the repository's existing `github.com/coder/websocket`
  dependency, connecting Speech Engine to any Iris `core.Provider` LLM and
  executable tools.

## What Changed

### New Additions

- **`providers/elevenlabs/speech_engine.go`**:
  - Constants: `SpeechEngineAuthHeader`, `SpeechEngineJWTIssuer`,
    `SpeechEngineJWTSubject`, `DefaultSpeechEngineClockSkew` (60s),
    `DefaultSpeechEngineMaxToolRounds` (5).
  - Sentinel errors: `ErrInvalidSpeechEngineConfig`, `ErrInvalidSpeechEngineToken`.
  - `VerifySpeechEngineJWT(apiKey, token, clockSkew)` (`SpeechEngineJWTClaims`):
    standard-library constant-time HS256 verification (supports both lowercase
    hex and raw 32-byte SHA-256 API-key digests; rejects `"none"` and non-HS256
    algorithms; checks `iss`, `sub`, `exp`, and `nbf` with leeway; never leaks
    credentials or tokens in errors).
  - `SpeechEngineToolExecutor`, `SpeechEngineToolExecutorFunc`, and structural
    support for `tools.Tool` (`Call(ctx, args)`).
  - `SpeechEngineConfig` (with `Validate()` and privacy-safe `String()`/`GoString()`).
  - `(*ElevenLabs).NewSpeechEngineHandler(cfg)` returning `*SpeechEngineHandler`
    implementing `http.Handler`:
    - Verifies `X-Elevenlabs-Speech-Engine-Authorization` on upgrade (401 on
      failure; optional `DisableAuth` escape hatch for IP-allowlisted proxies).
    - Handles `init`, `ping`->`pong`, `user_transcript` (array history or
      single string), `close`, and `error` frames.
    - Streams replies from any Iris `core.Provider` LLM (`StreamChat` with
      fallback to `Chat`) as `agent_response` frames with multi-round tool
      calling.
    - Cancels in-flight LLM generation immediately when a higher `event_id`
      arrives (interruption) and ignores stale/duplicate `event_id`s.
    - Emits optional `core.VoiceEvent` observations via `OnEvent` for metrics
      and session tracking.
- **`providers/elevenlabs/speech_engine_test.go`**:
  - Deterministic unit and `-race` tests covering HS256 JWT verification (valid
    hex/raw secrets, clock skew, expiration, wrong alg/iss/sub/signature, zero
    key leakage), config validation & privacy, 401 auth gate, streaming LLM +
    `ping`/`pong` + `close`, higher-`event_id` interruption cancellation,
    non-streaming LLM + tool calling, and upstream error/malformed/network
    handling with secret scrubbing.

### Modifications

- **`providers/elevenlabs/doc.go`**, **`docs/guides/speech.md`**, **`docs/PROVIDERS.md`**:
  - Documented the Speech Engine upstream protocol, security requirements,
    fallback guidance (`voice.Pipeline` for client-initiated audio streaming),
    and limitations.

## API & Behavior

```go
handler, err := provider.NewSpeechEngineHandler(elevenlabs.SpeechEngineConfig{
	LLM:          openAIProvider,
	Model:        "gpt-5",
	SystemPrompt: "Be concise and conversational.",
	Tools:        []core.Tool{weatherTool},
})
if err != nil {
	return err
}
http.Handle("/speech-engine", handler)
```

## Integration Notes

- Preserves strict separation between Iris-managed `voice.Pipeline` (`#156`),
  Speech Engine upstream server (`#157`), and hosted ElevenAgents (`#158`).
- `OnEvent func(core.VoiceEvent)` lets `#159` (voice metrics/tracing hooks)
  and Cortex/PetalFlow observe Speech Engine sessions using the same typed
  `core.VoiceEvent` model.

## Breaking Changes & Migration

None. Existing providers and clients compile and pass unchanged.

## Deferred / Out of Scope

- Speech Engine REST agent CRUD management (creating/updating `wsUrl` on
  ElevenLabs' control plane) — callers configure `wsUrl` via ElevenLabs'
  dashboard or REST API.
- Hosted ElevenAgents client WebSocket adapter — implemented separately in `#158`.
