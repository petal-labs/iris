## Summary

Defines the provider-agnostic full-duplex real-time voice session contract,
typed event taxonomy with turn IDs and interruption metadata, stale-audio turn
tracker, and bounded race-free event emitter in `core` for Issue #155
(`IRIS-VOICE-012`).

## Motivation

Downstream Iris-managed voice pipelines (`#156`), Speech Engine (`#157`),
hosted ElevenAgents sessions (`#158`), voice observability hooks (`#159`),
PetalFlow session nodes (`#252`/`#253`), and Cortex turn history (`#77`) all
require a single, provider-independent `VoiceSession` and `VoiceEvent` contract
that:
- Separates partial hypotheses from committed utterances (`IsFinal`).
- Correlates transcripts, assistant deltas, tool calls/results, audio chunks,
  and interruptions via explicit `TurnID` values.
- Cancels in-flight turns and prevents stale audio playback after barge-in or
  client cancellation.
- Guarantees bounded memory, clean channel closure, privacy-safe formatting,
  and race freedom under concurrent producers/consumers.

## What Changed

### New Additions

- **`core/voice_session.go`**:
  - Sentinel errors `ErrInvalidVoiceSessionConfig` and `ErrVoiceSessionClosed`,
    plus `DefaultVoiceEventBufferSize` (`64`).
  - `VoiceSessionState` (`connecting`, `active`, `listening`, `thinking`,
    `speaking`, `interrupted`, `closed`) with `IsValid()`.
  - `VoiceSessionConfig` with `Validate()`, privacy-safe `String()`/`GoString()`
    (omits `SystemPrompt` content and `Metadata` values).
  - `VoiceEventType` covering lifecycle (`session_started`, `session_state`,
    `session_ended`), turn & interruption (`turn_started`, `turn_completed`,
    `turn_interrupted`), partial vs. committed transcripts
    (`user_transcript_partial`, `user_transcript_committed`,
    `agent_text_delta`, `agent_text_committed`), audio (`audio_output`,
    `audio_output_ended`), tools (`tool_call`, `tool_result`), and `error`.
  - `VoiceInterruptionReason` (`barge_in`, `client_cancel`, `session_closed`)
    and `VoiceInterruption` (`CancelledTurnID`, `NextTurnID`, `Reason`,
    `AudioSequenceCutoff`).
  - `VoiceEvent` with `TurnID`, `Validate()`, and privacy-safe
    `String()`/`GoString()` omitting raw audio bytes, transcript text,
    assistant text, and tool argument/result payloads.
  - `VoiceSession` and optional `VoiceSessionProvider` interfaces,
    `AsVoiceSessionProvider` (walking `ProviderUnwrapper` chains), and
    `(*Client).StartVoiceSession`.
  - `VoiceTurnTracker` (`NewVoiceTurnTracker`, `StartTurn`,
    `StartTurnWithContext`, `ActiveTurnID`, `Interrupt`, `CompleteTurn`,
    `IsCurrentTurn`, `ObserveEvent`, `ShouldPlayAudio`, `Close`) with bounded
    cancelled-turn history (`128` entries) for producer- and consumer-side
    stale-audio suppression.
  - `VoiceEventEmitter` (`NewVoiceEventEmitter`, `Events`, `Err`, `Emit`,
    `Fail`, `Close`) with race-free, deadlock-free bounded emission and
    idempotent closure.
- **`core/voice_session_test.go`**:
  - Unit, privacy, validation, backpressure, cancellation, closure, and `-race`
    concurrency tests covering all types and helpers (95%+ statement coverage
    across `core`, ~100% across `voice_session.go`).

### Modifications

- **`core/doc.go`** and **`docs/guides/speech.md`**:
  - Documented the voice session/event contracts, stale-audio filtering model,
    privacy guarantees, and current limitations.

## API & Behavior

```go
sess, err := client.StartVoiceSession(ctx, core.VoiceSessionConfig{
	InputFormat:  core.AudioFormatPCM16000,
	OutputFormat: core.AudioFormatPCM16000,
})
if err != nil {
	return err
}
defer sess.Close()

tracker := core.NewVoiceTurnTracker("rx")
for evt := range sess.Events() {
	tracker.ObserveEvent(evt)
	if evt.Type == core.VoiceEventAudioOutput && tracker.ShouldPlayAudio(evt) {
		// Play evt.Audio.Data; stale chunks from interrupted turns are dropped.
	}
}
if err := <-sess.Err(); err != nil {
	return err
}
```

## Integration Notes

- Directly unblocks `#156` (Iris-managed voice pipeline), `#157` (Speech Engine
  adapter), and `#158` (ElevenAgents session adapter), all of which can compose
  `core.VoiceTurnTracker` and `core.VoiceEventEmitter`.
- Aligns with downstream Cortex `#77` (session/turn metadata) and PetalFlow
  `#252`/`#253` (session-oriented voice execution).
