## Summary

Implements the optional hosted **ElevenAgents** Conversational AI session
adapter (`core.VoiceSessionProvider` / `core.VoiceSession`) and signed URL
minting (`GET /v1/convai/conversation/get-signed-url`) in `providers/elevenlabs`
for Issue #158 (`IRIS-VOICE-015`).

## Motivation

Applications using ElevenLabs' hosted conversational agents need a clean Go
session adapter that supports private-agent signed URL authentication (without
leaking signed URL tokens or API keys), bidirectional audio/text streaming,
automatic `ping`/`pong` keepalives, interruption handling, client-side tool
calls/results, and clean resource teardown—while keeping hosted ElevenAgents
explicitly distinct from Iris-controlled `voice.Pipeline` (`#156`) and
`SpeechEngineHandler` (`#157`).

## What Changed

### New Additions

- **`providers/elevenlabs/agents.go`**:
  - `AgentSignedURLRequest`, `AgentSignedURLResponse` (storing `SignedURL` as
    `core.Secret` with full redaction in `String`/`GoString`/JSON), and
    `(*ElevenLabs).GetAgentSignedURL(ctx, req)` targeting
    `GET /v1/convai/conversation/get-signed-url`.
  - `AgentSessionConfig` (with `Validate()` and privacy-safe `String()`/`GoString()`
    omitting `SignedURL`, `SystemPrompt`, `FirstMessage`, and `DynamicVariables`).
  - `(*ElevenLabs).StartVoiceSession(ctx, core.VoiceSessionConfig)` implementing
    `core.VoiceSessionProvider`, plus `(*ElevenLabs).StartAgentSession(ctx, AgentSessionConfig)`
    supporting three auth modes:
    1. Automatic private-agent signed URL minting (`GetAgentSignedURL`) when an
       API key is configured and no `SignedURL` is provided.
    2. Pre-minted `SignedURL` connection (no API key required on client).
    3. Direct `/v1/convai/conversation?agent_id=...` dialing (`UseDirectAuth: true`).
  - `agentVoiceSession` implementing `core.VoiceSession`:
    - Optional `conversation_initiation_client_data` frame (user ID, dynamic
      variables, prompt/voice/language/first-message overrides).
    - `SendAudio` (`user_audio_chunk` base64 with size & 16-bit PCM byte-length
      validation), `SendText` (`user_message`), `SubmitToolResult`
      (`client_tool_result`), `Interrupt` (`user_activity` + `VoiceEventTurnInterrupted`),
      automatic `ping`->`pong` responses, and `Close()` cleanup.
    - Maps `conversation_initiation_metadata` (updating conversation ID &
      input/output audio formats), `tentative_user_transcript`, `user_transcript`,
      `agent_response`, `agent_response_correction`, `audio` (base64 decoded),
      `interruption`, `client_tool_call`, and `error` frames onto bounded
      `core.VoiceEventEmitter` with both API key and signed URL scrubbing.
- **`providers/elevenlabs/agents_test.go`**:
  - Deterministic unit and `-race` tests covering signed URL minting &
    redaction, private/pre-minted/direct auth modes, full audio/text/tool/
    interruption/ping-pong flows, validation & closed lifecycle, error secret
    scrubbing, full-buffer cancellation/Close, and concurrent safety.
- **`tests/integration/elevenlabs_test.go`**:
  - Added optional live `TestElevenLabs_AgentSession` gated on
    `ELEVENLABS_API_KEY` and `ELEVENLABS_AGENT_ID`.

### Modifications

- **`providers/elevenlabs/ws.go`**: Factored `dialWebSocketURL` out of
  `dialWebSocket` so pre-minted signed URLs reuse handshake error normalization,
  4 MiB read limit, and dual-secret scrubbing cleanly.
- **`providers/elevenlabs/provider.go`** & **`provider_test.go`**: Advertised
  `core.FeatureVoiceSession` in `Supports()` and verified
  `core.AsVoiceSessionProvider(p)`.
- **`providers/elevenlabs/doc.go`**, **`docs/guides/speech.md`**, **`docs/PROVIDERS.md`**:
  Documented ElevenAgents API, signed URL security, and hosted-reasoning boundaries.

## API & Behavior

```go
sess, err := client.StartVoiceSession(ctx, core.VoiceSessionConfig{
	AgentID: "agent_...",
})
if err != nil {
	return err
}
defer sess.Close()
```

## Integration Notes

- Completes all three distinct real-time voice modes in the FRD:
  1. Client-initiated Iris-managed pipeline (`voice.Pipeline`, `#156`)
  2. Server-side ElevenLabs Speech Engine (`elevenlabs.SpeechEngineHandler`, `#157`)
  3. Hosted ElevenAgents client (`elevenlabs.StartVoiceSession` / `StartAgentSession`, `#158`)
