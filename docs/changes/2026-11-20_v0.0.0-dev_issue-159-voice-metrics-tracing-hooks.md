## Summary

Adds privacy-safe voice metrics and tracing hooks in `core`
(`core.VoiceTelemetryHook`, `core.WithVoiceTelemetry`,
`core.ObserveVoiceSession`), wires them into `core.Client` speech methods and
`voice.Pipeline`, and implements OpenTelemetry span + metric instrumentation
(`contrib/otel.VoiceHook`) for Issue #159 (`IRIS-VOICE-016`).

## Motivation

Production voice applications need observability into speech request duration,
streaming first-chunk/first-audio latency, session duration, turn/interruption/
tool counts, input/output byte and character usage, and error rates without
ever exposing raw audio bytes, transcripts, prompts, or credentials in logs,
traces, or metric attributes.

## What Changed

### New Additions

- **`core/voice_telemetry.go`** & **`core/voice_telemetry_test.go`**:
  - `VoiceOperation` constants (`synthesize`, `stream_synthesize`,
    `realtime_synthesize`, `transcribe`, `realtime_transcribe`,
    `voice_session`, `voice_turn`).
  - Strictly privacy-safe event structs: `VoiceRequestStartEvent`,
    `VoiceFirstChunkEvent` (with `FirstChunkLatency()`),
    `VoiceRequestEndEvent` (with `Duration()`), `VoiceSessionStartEvent`,
    `VoiceTurnEndEvent` (with `Duration()`), and `VoiceSessionEndEvent` (with
    `Duration()`). None of these structs contain fields for API keys, signed
    URLs, raw audio bytes, prompts, transcripts, assistant text, or tool payloads.
  - `VoiceTelemetryHook` interface and zero-cost `NoopVoiceTelemetryHook`.
  - `ObserveVoiceSession(ctx, sess, hook, meta)` race-free, deadlock-free
    wrapper for any `core.VoiceSession` recording input/output audio bytes,
    per-turn first-audio latency, tool calls, interruptions, errors, and
    session duration.
- **`contrib/otel/voice_hook.go`** & **`contrib/otel/voice_hook_test.go`**:
  - `VoiceHook` (`NewVoiceHook`, `WithVoiceTracerProvider`,
    `WithVoiceMeterProvider`, `WithVoiceScopeName`, `WithVoiceRecordError`,
    `WithVoiceAttributes`) implementing `core.VoiceTelemetryHook` with OTel
    client/internal spans (`first_chunk` span events, status/error recording)
    and counters/histograms (`iris.voice.requests`, `iris.voice.errors`,
    `iris.voice.request.duration_ms`, `iris.voice.first_chunk.latency_ms`,
    `iris.voice.sessions`, `iris.voice.session.duration_ms`,
    `iris.voice.turns`, `iris.voice.interruptions`, `iris.voice.audio.bytes`,
    `iris.voice.input_characters`).

### Modifications

- **`core/client.go`**, **`core/speech.go`**, **`core/voice_session.go`**:
  - Added `WithVoiceTelemetry(hook)` option and wired voice telemetry into
    `Client.Synthesize`, `Client.StreamSynthesize` (including non-copying first-
    chunk latency capture), `Client.Transcribe`, and `Client.StartVoiceSession`.
- **`voice/pipeline.go`** & **`voice/pipeline_test.go`**:
  - Added `PipelineConfig.Telemetry` wrapping sessions via
    `core.ObserveVoiceSession` when configured.
- **`contrib/otel/attributes.go`**, **`contrib/otel/doc.go`**, **`core/doc.go`**, **`docs/guides/speech.md`**:
  - Added voice OTel attribute constants and updated public documentation.

## API & Behavior

```go
voiceHook := irisotel.NewVoiceHook(
	irisotel.WithVoiceTracerProvider(tp),
	irisotel.WithVoiceMeterProvider(mp),
)

client := core.NewClient(provider, core.WithVoiceTelemetry(voiceHook))
pipeline, _ := voice.NewPipeline(voice.PipelineConfig{
	LLM:         openAIProvider,
	LLMModel:    "gpt-5",
	RealtimeTTS: elevenLabsProvider,
	VoiceID:     "JBFqnCBsd6RMkjVDRZzb",
	Telemetry:   voiceHook,
})
```

## Integration Notes

- Works identically across `core.Client` speech methods, Iris-managed
  `voice.Pipeline`, and hosted `ElevenAgents` sessions (`StartVoiceSession`),
  and pairs with `SpeechEngineHandler.OnEvent` for upstream server tracking.
- Zero new third-party dependencies added to root `go.mod` or `contrib/otel/go.mod`.

## Breaking Changes & Migration

None. `NoopVoiceTelemetryHook` is used by default; all existing callers and
providers compile and pass unchanged.
