## Summary

Adds the `github.com/petal-labs/iris/providers/elevenlabs` package implementing
ElevenLabs provider configuration, `New` / `NewFromEnv`, API key redaction,
custom HTTP client and base URL options, per-provider timeouts, ElevenLabs typed
error normalization, verified model catalog metadata, registry registration, and
concurrent-safe HTTP transport helpers for Issue #146 (`IRIS-VOICE-003`).

## Motivation

Before adding synchronous TTS (`#147`), HTTP streaming TTS (`#148`), and
file-based Scribe transcription (`#149`), ElevenLabs needs a dedicated provider
package with secure `core.Secret` credential handling (`xi-api-key`),
configurable HTTP transport and timeouts, and ElevenLabs-specific error parsing
(including structured `detail` objects, FastAPI 422 validation errors mapped to
`core.ErrBadRequest`, `request-id`, and `Retry-After`).

## What Changed

### New Additions

- **`providers/elevenlabs/doc.go`**: Package overview, usage example,
  concurrency/timeout semantics, privacy redaction guarantees, and current
  limitations.
- **`providers/elevenlabs/options.go`**: `DefaultBaseURL`
  (`https://api.elevenlabs.io`), `DefaultAPIKeyEnvVar` (`ELEVENLABS_API_KEY`),
  `ErrAPIKeyNotFound`, `Config` (with redacted `String()` / `GoString()` and
  `core.Secret` JSON redaction), `Option`, `WithAPIKey`, `WithBaseURL`,
  `WithHTTPClient`, `WithHeader`, and `WithTimeout`.
- **`providers/elevenlabs/models.go`**: Verified ElevenLabs model ID constants
  (`ModelElevenMultilingualV2`, `ModelElevenFlashV25`, `ModelElevenV3`,
  `ModelScribeV1`, `ModelScribeV2`), static catalog, and defensive-copy
  `GetModelInfo(id)`. Model capabilities remain unset until corresponding
  endpoints are implemented so unimplemented combinations are never advertised.
- **`providers/elevenlabs/errors.go`**: `normalizeError` mapping ElevenLabs HTTP
  statuses (including `422` -> `core.ErrBadRequest`), parsing object, string,
  and FastAPI validation-list `detail` payloads, attaching `request-id` and
  `Retry-After`, and truncating oversized bodies (`4096` bytes); plus
  `newNetworkError` and `newDecodeError`.
- **`providers/elevenlabs/provider.go`**: Concurrent-safe `ElevenLabs` struct
  implementing `core.Provider` (`New`, `NewFromEnv`, `ID`, `Models`, `Supports`,
  `Chat`/`StreamChat` returning `core.ErrNotSupported`, redacted `String` and
  `GoString`).
- **`providers/elevenlabs/http.go`**: Shared internal HTTP helpers
  (`requireAPIKey`, `endpointURL`, `buildHeaders` with authoritative
  `xi-api-key`, `doRequest` with `timeoutx.Apply` and `cancelOnClose` body
  wrapping so response bodies remain readable after `doRequest` returns).
- **`providers/elevenlabs/register.go`**: Registers `"elevenlabs"` with
  `providers.Register` in `init()`.
- **`providers/elevenlabs/provider_test.go`**, **`errors_test.go`**,
  **`http_test.go`**: Race-tested unit tests covering construction, `NewFromEnv`,
  API key/header redaction, registry registration, model catalog defensive
  copies, typed error normalization, preflight empty-key rejection, timeouts,
  context cancellation, and concurrent safety.

## Technical Specification

### Data Schemas / Types

```go
const (
	DefaultBaseURL      = "https://api.elevenlabs.io"
	DefaultAPIKeyEnvVar = "ELEVENLABS_API_KEY"
)

var ErrAPIKeyNotFound = errors.New("elevenlabs: ELEVENLABS_API_KEY environment variable not set")

type Config struct {
	APIKey     core.Secret   `json:"api_key"`
	BaseURL    string        `json:"base_url"`
	HTTPClient *http.Client  `json:"-"`
	Headers    http.Header   `json:"-"`
	Timeout    time.Duration `json:"timeout_ns,omitempty"`
}

type Option func(*Config)

type ElevenLabs struct {
	config Config
}
```

### Go Package API

- `func New(apiKey string, opts ...Option) *ElevenLabs` — constructs an
  immutable, concurrent-safe ElevenLabs provider.
- `func NewFromEnv(opts ...Option) (*ElevenLabs, error)` — reads
  `ELEVENLABS_API_KEY` and returns `ErrAPIKeyNotFound` if unset or blank.
- `func WithAPIKey(key string) Option`
- `func WithBaseURL(rawURL string) Option`
- `func WithHTTPClient(client *http.Client) Option`
- `func WithHeader(key, value string) Option`
- `func WithTimeout(d time.Duration) Option`
- `func GetModelInfo(id core.ModelID) *core.ModelInfo`
- `(*ElevenLabs)` implements `core.Provider` (`ID() == "elevenlabs"`,
  `Chat`/`StreamChat` return `*core.ProviderError` wrapping `core.ErrNotSupported`).

### Configuration

- **`ELEVENLABS_API_KEY`** (environment variable, string, required by `NewFromEnv`,
  no default): ElevenLabs API key stored as `core.Secret` and sent in the
  `xi-api-key` HTTP header.

## Usage Examples

### Example: Initializing ElevenLabs from Environment

```go
provider, err := elevenlabs.NewFromEnv(
	elevenlabs.WithTimeout(30 * time.Second),
)
if err != nil {
	return err
}
client := core.NewClient(provider)
```

### Example: Handling Missing API Key (Error Case)

```go
_, err := elevenlabs.NewFromEnv()
if errors.Is(err, elevenlabs.ErrAPIKeyNotFound) {
	// Prompt user or secret manager to supply ELEVENLABS_API_KEY.
}
```
