## Summary

Syncs the static provider catalogs in `providers/<name>/models.go` against the
models.dev catalog (`https://models.dev/api.json`) as of 2026-10-23. This is the
removal half of the catalog refresh cycle: new flagships land for every chat
provider, and model ids that have disappeared from models.dev are deleted.

Breaking: this release deletes exported `core.ModelID` constants for the first
time (the 2026-09-05 refresh was purely additive). Any caller pinning a removed
constant must move to a current id.

## Motivation

Issue #138 asks Iris to remove deprecated provider models and add new ones,
using models.dev as the reference. The catalogs are the SDK's source of truth
for model discovery (`Provider.Models()`), capability queries
(`SupportsToolCalling`, `IsReasoningModel`, ...) and — on OpenAI — endpoint
routing, so a deprecated id lingers as a request the upstream API rejects.

### Related Changes

- **`providers/gemini/models.go`** — `isGemini3Model` was renamed to
  `usesThinkingLevel` and now matches the `gemini-3` and `gemini-4` prefixes,
  since Gemini 4 uses the same `thinkingLevel` reasoning control.
- **`cli/commands/init.go`** — `defaultModel` scaffolds moved to current
  flagships: `gpt-5.6` (OpenAI), `claude-sonnet-5-5` (Anthropic),
  `gemini-3.8-flash` (Gemini), `grok-4.7` (xAI), `glm-5.3-flash` (Z.ai), and
  `meta-llama/Llama-3.1-8B-Instruct` (Hugging Face). The old xAI default
  `grok-4-1-fast-non-reasoning` no longer exists.
- **`examples/` and `tests/integration/xai_test.go`** — moved off deleted ids:
  xAI examples and integration defaults now use `xai.ModelGrok47`, and the
  `xai-reasoning` example moved from `ModelGrok3Mini` to `ModelGrok47`. The
  example may print less (or no) reasoning trace depending on which models
  currently surface `reasoning_content`; keeping it on a deleted id was not an
  option.
- **`docs/PROVIDERS.md`, `docs/guides/multimodal.md`,
  `docs/guides/provider-quickstarts.md`, `README.md`** — model tables and
  examples resynced with the catalogs.

Deliberately unchanged: dated snapshots (`claude-opus-4-5-20251101`,
`gpt-4o-2024-*`) remain excluded; Perplexity's catalog needed no change (it
already matches models.dev); Ollama discovers models at runtime; Hugging Face
routes arbitrary hub ids; Voyage AI is not cataloged on models.dev.

## Technical Specification

Capabilities were derived from the models.dev fields `reasoning`, `tool_call`,
`structured_output`, and `modalities.output`, following the per-provider
conventions recorded in `2026-09-05_v1.0.0_provider-model-catalog-refresh.md`
(`FeatureStructuredOutput` only in the OpenAI and Azure Foundry catalogs).

## Integration Notes

- **Breaking:** exported constants were removed from five provider packages.
  Code referencing `openai.ModelGPT5Codex`, `anthropic.ModelClaude35HaikuLatest`,
  `gemini.ModelGemini3Pro`, `xai.ModelGrok3`, `zai.ModelGLMForCoding` (among
  others) fails to compile and must move to a current id. String literals are
  unaffected at compile time but fail at runtime with an unknown-model error or
  (on OpenAI) a fallback to Chat Completions.
- `go build ./...`, `go vet ./...`, `golangci-lint run`, and `go test ./...`
  pass; the only failure, `cli/keystore TestNewKeystoreLegacyMode`, predates
  this change and reproduces on a clean checkout.
