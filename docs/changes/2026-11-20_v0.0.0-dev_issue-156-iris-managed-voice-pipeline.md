## Summary

Adds the provider-independent `github.com/petal-labs/iris/voice` package
implementing an Iris-managed full-duplex streaming voice pipeline
(`Streaming STT -> arbitrary Iris LLM provider -> streaming TTS`) with
interruption/barge-in cancellation, automatic and caller-driven tool handling,
and bounded history/event delivery for Issue #156 (`IRIS-VOICE-013`).

## Motivation

Applications using Iris need to combine real-time speech recognition (e.g.,
ElevenLabs Scribe v2 Realtime) and low-latency streaming synthesis (e.g.,
ElevenLabs WebSocket TTS) with *any* Iris chat provider (OpenAI, Anthropic,
Gemini, Ollama, xAI, Perplexity, Azure AI Foundry, etc.) while keeping
reasoning, tool execution, history boundaries, and barge-in cancellation under
application control rather than locked inside a hosted conversational agent.

## What Changed

### New Additions

- **`voice/doc.go`**: Package overview, architectural boundaries, usage example,
  error semantics, and limitations.
- **`voice/pipeline.go`**:
  - `PipelineConfig` (with `Validate()` and privacy-safe `String()`/`GoString()`
    omitting `SystemPrompt`), `ToolExecutor`, `ToolExecutorFunc`, and
    `RegistryToolExecutor(*tools.Registry)`.
  - `Pipeline` (`NewPipeline`, `(*Pipeline).StartVoiceSession`) implementing
    `core.VoiceSessionProvider` with safe per-session overrides (`Model`,
    `VoiceID`, `VoiceSettings`, `SystemPrompt`, `Language`, `InputFormat`,
    `OutputFormat`, `Tools`, `EventBufferSize`).
  - Sentinel errors `ErrInvalidPipelineConfig`, `ErrToolCallNotFound`,
    `ErrMaxToolRoundsExceeded` and bounded defaults (`DefaultMaxToolRounds = 5`,
    `DefaultMaxHistoryMessages = 64`, `DefaultToolTimeout = 30s`).
- **`voice/session.go`**:
  - `Session` implementing `core.VoiceSession` (plus `CommitAudio` and
    defensive `History()`):
    - Streams user audio to `core.RealtimeSpeechRecognizer`, emits partial vs.
      committed transcripts, triggers automatic barge-in on non-empty user
      partial speech during active assistant turns (unless `DisableBargeIn`).
    - Runs serialized assistant turns on a dedicated worker using
      `core.VoiceTurnTracker` and `core.VoiceEventEmitter`.
    - Streams LLM tokens (`StreamChat`) directly into incremental-input
      `core.RealtimeSpeechSynthesizer` (opened lazily on first text delta so
      tool-only rounds never open an unused TTS WebSocket), with automatic
      fallback to non-streaming `Chat` and/or HTTP `SpeechSynthesizer.StreamSynthesize`.
    - Supports three tool patterns: explicit `ToolExecutor` (including
      `*tools.Registry`), executable `tools.Tool` (`Call`), and caller-driven
      `SubmitToolResult` for schema-only `core.Tool` definitions (registering
      pending waiters before emitting `VoiceEventToolCall` to avoid races).
    - Guarantees clean cancellation, stale-audio suppression, bounded history
      trimming (never leaving an orphaned `RoleTool` message at index 0), and
      deadlock-free `Close()` even when `Events()` is full.
- **`voice/pipeline_test.go`**:
  - Deterministic unit and concurrency (`-race`) tests covering end-to-end
    streaming STT->LLM->RealtimeTTS, non-streaming LLM + HTTP TTS fallback,
    auto & external tool handling, `MaxToolRounds`, barge-in & explicit
    `Interrupt` with stale-audio suppression, STT/LLM/validation failures,
    parent context cancellation, full-buffer `Close()`, and concurrent calls.

### Modifications

- **`docs/guides/speech.md`**: Documented the `voice` package pipeline API,
  tool handling modes, interruption/barge-in behavior, and updated remaining
  planned items.

## API & Behavior

```go
pipeline, err := voice.NewPipeline(voice.PipelineConfig{
	STT:         elevenLabsProvider,
	LLM:         openAIProvider,
	LLMModel:    "gpt-5",
	RealtimeTTS: elevenLabsProvider,
	VoiceID:     "JBFqnCBsd6RMkjVDRZzb",
	Tools:       []core.Tool{weatherTool},
})
if err != nil {
	return err
}

sess, err := pipeline.StartVoiceSession(ctx, core.VoiceSessionConfig{
	InputFormat:  core.AudioFormatPCM16000,
	OutputFormat: core.AudioFormatPCM16000,
})
if err != nil {
	return err
}
defer sess.Close()
```

## Integration Notes

- Unblocks `#157` (Speech Engine adapter), `#159` (voice metrics & tracing
  hooks), `#160` (PetalFlow voice integration specification), and `#162`
  (real-time voice-agent integration tests).
- Keeps `providers/elevenlabs` completely decoupled from `voice`; any provider
  implementing `core.RealtimeSpeechRecognizer`, `core.Provider`, and
  `core.RealtimeSpeechSynthesizer`/`core.SpeechSynthesizer` can be composed.
