## Summary

Adds optional `SpeechSynthesizer` and `SpeechRecognizer` provider interfaces,
speech/voice `Feature` constants, capability discovery helpers
(`AsSpeechSynthesizer`, `AsSpeechRecognizer`, `ModelsWithCapability`,
`ProviderSupportsModelFeature`), and `Client` convenience methods
(`Client.Synthesize`, `Client.StreamSynthesize`, `Client.Transcribe`) in
`github.com/petal-labs/iris/core` for Issue #145 (`IRIS-VOICE-002`). Existing
`core.Provider` implementations remain untouched and backwards-compatible.

## Motivation

Iris keeps `core.Provider` minimal so chat-only and embedding providers do not
have to implement audio endpoints. Adding optional speech interfaces and
unwrap-aware discovery (matching `AsEmbeddingProvider`, `AsReranker`, and
`AsImageGenerator`) allows providers such as ElevenLabs (`#146`–`#150`) and
downstream callers (PetalFlow `#249`–`#251`) to discover and invoke synthesis
and transcription with consistent validation, rate limiting, timeouts, retries,
and privacy-safe telemetry.

## What Changed

### New Additions

- **`core/speech.go`**:
  - Feature constants: `FeatureSpeechSynthesis`, `FeatureSpeechSynthesisStreaming`,
    `FeatureSpeechRecognition`, `FeatureSpeechRecognitionRealtime`,
    `FeatureVoiceSession`.
  - Optional interfaces: `SpeechSynthesizer` (`Synthesize`, `StreamSynthesize`)
    and `SpeechRecognizer` (`Transcribe`).
  - Discovery helpers: `AsSpeechSynthesizer(p Provider)`,
    `AsSpeechRecognizer(p Provider)` (walking `ProviderUnwrapper` chains),
    `ModelsWithCapability(p Provider, feature Feature)`, and
    `ProviderSupportsModelFeature(p Provider, model ModelID, feature Feature)`.
  - Client methods: `(*Client).Synthesize`, `(*Client).StreamSynthesize`, and
    `(*Client).Transcribe` applying request validation, capability discovery,
    rate limiting, timeouts (`ErrTimeout` remapping), retry policy (excluding
    non-rewindable `io.Reader` transcription requests), and telemetry without
    logging audio or transcript content.
- **`core/speech_test.go`**: Race-tested unit tests covering feature constants,
  direct/unwrapped/cyclic capability discovery, model capability filtering and
  rejection of unverified models, and `Client.Synthesize`,
  `Client.StreamSynthesize`, and `Client.Transcribe` success, failure, retry,
  rate-limit, timeout, and cancellation paths.

### Modifications

- **`core/doc.go`**: Documented the new speech `Feature` constants, optional
  speech interfaces, discovery helpers, `Client` speech methods, and
  limitations.

## Technical Specification

### Data Schemas / Types

```go
const (
	FeatureSpeechSynthesis           Feature = "speech_synthesis"
	FeatureSpeechSynthesisStreaming  Feature = "speech_synthesis_streaming"
	FeatureSpeechRecognition         Feature = "speech_recognition"
	FeatureSpeechRecognitionRealtime Feature = "speech_recognition_realtime"
	FeatureVoiceSession              Feature = "voice_session"
)

type SpeechSynthesizer interface {
	Synthesize(ctx context.Context, req *SpeechRequest) (*SpeechResponse, error)
	StreamSynthesize(ctx context.Context, req *SpeechRequest) (*SpeechStream, error)
}

type SpeechRecognizer interface {
	Transcribe(ctx context.Context, req *TranscriptionRequest) (*TranscriptionResponse, error)
}
```

### Go Package API

- `func AsSpeechSynthesizer(p Provider) (SpeechSynthesizer, bool)` — discovers
  `SpeechSynthesizer` on `p` or its `ProviderUnwrapper` chain.
- `func AsSpeechRecognizer(p Provider) (SpeechRecognizer, bool)` — discovers
  `SpeechRecognizer` on `p` or its `ProviderUnwrapper` chain.
- `func ModelsWithCapability(p Provider, feature Feature) []ModelInfo` — returns
  all catalog models on `p` advertising `feature`.
- `func ProviderSupportsModelFeature(p Provider, model ModelID, feature Feature) bool` —
  reports whether `p` explicitly advertises `feature` for `model` (returns
  `false` for unknown/unverified models).
- `func (c *Client) Synthesize(ctx context.Context, req *SpeechRequest) (*SpeechResponse, error)` —
  validates `req`, discovers `SpeechSynthesizer`, and applies rate limiting,
  timeout, retry, and telemetry.
- `func (c *Client) StreamSynthesize(ctx context.Context, req *SpeechRequest) (*SpeechStream, error)` —
  validates `req`, discovers `SpeechSynthesizer`, applies rate limiting and
  stream-lifetime timeout, and relays stream-completion telemetry.
- `func (c *Client) Transcribe(ctx context.Context, req *TranscriptionRequest) (*TranscriptionResponse, error)` —
  validates `req`, discovers `SpeechRecognizer`, and applies rate limiting,
  timeout, telemetry, and retries (for `AudioData` inputs only; `Reader` inputs
  are attempted once).

## Usage Examples

### Example: Capability Discovery and Synthesis via Client

```go
if _, ok := core.AsSpeechSynthesizer(provider); !ok {
	return core.ErrNotSupported
}
if !core.ProviderSupportsModelFeature(provider, "eleven_flash_v2_5", core.FeatureSpeechSynthesisStreaming) {
	return core.ErrNotSupported
}

client := core.NewClient(provider)
stream, err := client.StreamSynthesize(ctx, &core.SpeechRequest{
	Model:   "eleven_flash_v2_5",
	VoiceID: "voice_123",
	Text:    "Hello from Iris.",
	Format:  core.AudioFormatPCM16000,
})
if err != nil {
	return err
}
resp, err := core.DrainSpeechStream(ctx, stream)
```

### Example: Handling Unsupported Provider (Error Case)

```go
_, err := client.Transcribe(ctx, &core.TranscriptionRequest{
	Model: "scribe_v2",
	Audio: &core.AudioData{Data: wavBytes, Format: core.AudioFormatWAV16000},
})
if errors.Is(err, core.ErrNotSupported) {
	// Provider does not implement core.SpeechRecognizer.
}
```
