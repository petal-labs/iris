## Summary

Adds comprehensive privacy, bounded retry, timeout, resource cleanup, and
concurrency reliability tests for `providers/elevenlabs`, hardens
`core.ProviderError` against upstream API key reflection, and adds optional
credentialed live integration tests under `tests/integration/elevenlabs_test.go`
for Issue #150 (`IRIS-VOICE-007`).

## Motivation

Before shipping the ElevenLabs MVP, Iris requires verified evidence that default
logging and telemetry never leak secrets, raw audio, or transcripts; retries
remain bounded and honor `Retry-After` without retrying non-retryable 4xx errors
or single-pass `io.Reader` inputs; HTTP response bodies and goroutines are
cleaned up on errors and cancellations; and the wire implementation passes live
against the real ElevenLabs API.

## What Changed

### New Additions

- **`providers/elevenlabs/reliability_test.go`**:
  - `TestPrivacyNoSecretsAudioOrTranscriptsInDefaultLogsAndTelemetry`: audits
    `slog`, `fmt.Sprintf("%v"/"%#v")`, `core.TelemetryHook`, and hostile
    key-reflecting `ProviderError` payloads across `Synthesize`,
    `StreamSynthesize`, and `Transcribe` to guarantee zero leakage of API keys,
    custom secret headers, synthesis text, prompts, raw audio, or transcripts.
  - `TestRetrySynthesize4295xxAndNonRetryable`: verifies 429 (`Retry-After`) and
    503 recovery, strict `MaxRetries` bounding on persistent 500s, non-retry of
    400/401/403/404/422, and prompt cancellation during `Retry-After` waits.
  - `TestRetryTranscribeAudioDataVsReader`: verifies in-memory `AudioData`
    retries 429/502 while `io.Reader` inputs are strictly attempted once.
  - `TestResourceCleanupBodiesAndGoroutines`: verifies HTTP response bodies are
    closed across 200/400/429/500 responses and repeated stream/transcription
    cancellations leave zero leaked goroutines.
  - `TestConcurrentMixedSpeechOperations`: exercises concurrent `Synthesize`,
    `StreamSynthesize`, and `Transcribe` sharing one `*ElevenLabs` and
    `*core.Client` under `-race`.
- **`tests/integration/elevenlabs_test.go`** (`//go:build integration`):
  - `TestElevenLabs_Synthesize_And_Transcribe_RoundTrip`: live `Synthesize`
    (`eleven_flash_v2_5`, `mp3_44100_128`) -> `Transcribe` (`scribe_v2`, word
    timestamps) round-trip logging metadata only.
  - `TestElevenLabs_StreamSynthesize`: live HTTP streaming TTS verifying
    incremental chunks, sequence ordering, terminal marker, and `Final` usage.
  - `TestElevenLabs_InvalidAPIKey_ReturnsUnauthorized`: verifies live `401`
    maps to `core.ErrUnauthorized` with API key redacted.

### Modifications

- **`providers/elevenlabs/errors.go`** & **`http.go`**: Added `redactSecretError`
  to scrub the configured API key from `ProviderError.Message` and
  `ProviderError.Body` on HTTP and transport errors.
- **`providers/elevenlabs/doc.go`**: Documented error-body secret scrubbing.
- **`tests/integration/helpers.go`**: Added `skipIfNoElevenLabsKey` and
  `getElevenLabsKey` matching existing provider helpers.
