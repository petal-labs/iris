## Summary

Adds the provider-agnostic `core.RealtimeSpeechRecognizer` /
`core.RealtimeTranscriptionSession` streaming STT contract in `core` and
implements real-time ElevenLabs Scribe WebSocket transcription
(`wss://api.elevenlabs.io/v1/speech-to-text/realtime` with `scribe_v2_realtime`)
in `providers/elevenlabs` for Issue #153 (`IRIS-VOICE-010`).

## Motivation

Low-latency voice agents and real-time transcription pipelines need incremental
partial hypotheses distinct from committed final utterances, preflight input
chunk validation, bounded buffers, and clean cancellation/teardown over
WebSockets. Adding a shared `wsConn`/`wsDialer` layer backed by
`github.com/coder/websocket` also establishes the WebSocket transport foundation
for incremental-input TTS (`#154`) and ElevenAgents sessions (`#158`).

## What Changed

### New Additions

- **`core/speech_realtime.go`** & **`core/speech_realtime_test.go`**:
  - `ErrRealtimeSessionClosed`, `CommitStrategy` (`""`, `"manual"`, `"vad"`),
    `RealtimeTranscriptionConfig` (with `Validate()`), `RealtimeTranscriptEventType`
    (`session_started`, `partial`, `committed`), privacy-safe `RealtimeTranscriptEvent`,
    `RealtimeTranscriptionSession` interface (`SendAudio`, `Commit`, `Events`, `Err`, `Close`),
    `RealtimeSpeechRecognizer` optional provider interface, `AsRealtimeSpeechRecognizer`
    discovery helper, and `(*Client).StartRealtimeTranscription`.
- **`providers/elevenlabs/ws.go`**:
  - Internal `wsConn`/`wsDialer` abstraction backed by `github.com/coder/websocket`
    with 4 MiB per-message read limit (`SetReadLimit`), `https`->`wss` / `http`->`ws`
    URL conversion, `xi-api-key` auth header propagation, and HTTP handshake error
    normalization with API key scrubbing.
- **`providers/elevenlabs/stt_realtime.go`** & **`stt_realtime_test.go`**:
  - `ModelScribeV2Realtime = "scribe_v2_realtime"` and
    `DefaultRealtimeSTTModel = ModelScribeV2Realtime`, `DefaultRealtimeMaxChunkBytes`
    (256 KiB), `DefaultRealtimeEventBufferSize` (32 events).
  - `(*ElevenLabs).StartRealtimeTranscription(ctx, cfg)` implementing
    `core.RealtimeSpeechRecognizer`:
    - Validates mono PCM (`8000`/`16000`/`22050`/`24000`/`44100`/`48000Hz`) and
      `ulaw_8000` formats before dialing.
    - Enforces chunk validation in `SendAudio` (non-empty non-final chunks,
      `max_chunk_bytes` limit, session format match, even byte length for 16-bit
      PCM, closed-session guard) and serializes WebSocket writes.
    - Streams `input_audio_chunk` JSON messages (`audio_base_64`, `sample_rate`,
      `commit`) and maps server events (`session_started`, `partial_transcript`,
      `committed_transcript`, `committed_transcript_with_timestamps`, and
      typed server errors) onto a bounded `Events()` channel.
    - Guarantees clean teardown and channel closure on `Close()` or context
      cancellation, even when a slow consumer leaves `Events()` full.

## Technical Specification

### Data Schemas / Types

```go
type CommitStrategy string // "", "manual", "vad"

type RealtimeTranscriptionConfig struct {
	Model             ModelID           `json:"model,omitempty"`
	Format            AudioFormat       `json:"format"`
	Language          string            `json:"language,omitempty"`
	CommitStrategy    CommitStrategy    `json:"commit_strategy,omitempty"`
	IncludeTimestamps bool              `json:"include_timestamps,omitempty"`
	MaxChunkBytes     int               `json:"max_chunk_bytes,omitempty"`
	EventBufferSize   int               `json:"event_buffer_size,omitempty"`
	Metadata          map[string]string `json:"metadata,omitempty"`
}

type RealtimeTranscriptEvent struct {
	Type       RealtimeTranscriptEventType `json:"type"`
	SessionID  string                      `json:"session_id,omitempty"`
	Transcript *TranscriptionResponse      `json:"transcript,omitempty"`
	IsFinal    bool                        `json:"is_final,omitempty"`
	Timestamp  time.Time                   `json:"timestamp,omitempty"`
}

type RealtimeTranscriptionSession interface {
	SendAudio(ctx context.Context, chunk AudioChunk) error
	Commit(ctx context.Context) error
	Events() <-chan RealtimeTranscriptEvent
	Err() <-chan error
	Close() error
}

type RealtimeSpeechRecognizer interface {
	StartRealtimeTranscription(ctx context.Context, cfg RealtimeTranscriptionConfig) (RealtimeTranscriptionSession, error)
}
```

## Usage Examples

### Example: Real-Time Scribe Streaming Session

```go
sess, err := client.StartRealtimeTranscription(ctx, core.RealtimeTranscriptionConfig{
	Model:             elevenlabs.ModelScribeV2Realtime,
	Format:            core.AudioFormatPCM16000,
	CommitStrategy:    core.CommitStrategyManual,
	IncludeTimestamps: true,
})
if err != nil {
	return err
}
defer sess.Close()

if err := sess.SendAudio(ctx, core.AudioChunk{Data: pcmChunk, Format: core.AudioFormatPCM16000, Sequence: 0}); err != nil {
	return err
}
if err := sess.Commit(ctx); err != nil {
	return err
}
for evt := range sess.Events() {
	if evt.Type == core.RealtimeTranscriptEventCommitted && evt.Transcript != nil {
		// Stable committed utterance (evt.IsFinal == true)
	}
}
```
