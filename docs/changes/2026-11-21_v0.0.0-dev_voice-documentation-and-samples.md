## Summary

Reviews and updates Iris documentation and runnable samples to reflect the full
ElevenLabs speech and real-time voice-agent feature set, adds a **Voice**
column and detailed voice breakdown to the provider compatibility matrix in
`docs/PROVIDERS.md`, adds four new unit-tested voice/speech examples, and
accurately documents current CLI capabilities (`iris keys set elevenlabs` vs.
SDK-only speech/voice operations).

## Motivation

Following completion of the ElevenLabs Voice Integration (`#144`–`#162`),
several top-level docs (`README.md`, `docs/PROVIDERS.md`, `docs/ARCHITECTURE.md`,
`docs/DEVELOPMENT.md`, `docs/SECURITY.md`, `docs/guides/provider-quickstarts.md`)
still reflected pre-voice or MVP-only capabilities, the compatibility matrix
lacked a voice-support column, and `examples/` only contained the three MVP
speech samples without runnable samples for voice discovery, `voice.Pipeline`,
`SpeechEngineHandler`, or `ElevenAgents`.

## What Changed

### New Additions

- **`examples/speech/elevenlabs-voices/`**: Runnable read-only voice discovery
  and voice settings example (`ListVoices`, `GetVoice`, `GetVoiceSettings`)
  with offline unit tests (`main_test.go`).
- **`examples/voice/pipeline/`**: Runnable Iris-managed full-duplex voice
  pipeline example (`voice.Pipeline` composing OpenAI LLM streaming +
  ElevenLabs Flash v2.5 WebSocket TTS + optional Scribe v2 Realtime PCM input,
  `core.VoiceTurnTracker`, and `core.VoiceTelemetryHook`) with offline unit
  tests (`main_test.go`).
- **`examples/voice/speech-engine/`**: Runnable ElevenLabs Speech Engine
  upstream WebSocket server example (`elevenlabs.NewSpeechEngineHandler`
  `http.Handler` with HS256 JWT auth + `/healthz`) with offline unit tests
  (`main_test.go`).
- **`examples/voice/elevenagents/`**: Runnable hosted ElevenAgents session and
  backend signed-URL minting example (`client.StartVoiceSession`,
  `GetAgentSignedURL` with redacted logging) with offline unit tests
  (`main_test.go`).

### Modifications

- **`docs/PROVIDERS.md`**: Added a `Voice` column to the Feature Support Matrix,
  added a Voice & Speech Support Breakdown table, updated the ElevenLabs row in
  Supported Providers, and added a `Real-time voice agents` row to Choosing a
  Provider.
- **`README.md`**: Added ElevenLabs to the Unified SDK provider list, added
  Speech/Voice/Voice Agents/Voice Telemetry bullets to SDK Features, added
  `iris keys set elevenlabs` under Using the CLI with an accurate note that
  CLI speech/voice subcommands are not yet implemented, and linked the Speech
  and PetalFlow Voice guides in the Documentation table.
- **`docs/guides/provider-quickstarts.md`**: Added an `Using ElevenLabs (Speech & Voice)` quickstart section.
- **`docs/guides/speech.md`**: Added `ELEVENLABS_AGENT_ID`, updated available
  options (`WithVoiceManagementEnabled`, `WithVoiceAuthorizer`), added a CLI
  Support note, and documented all 7 speech/voice runnable examples.
- **`docs/ARCHITECTURE.md`**: Added all 5 speech/voice optional capability
  interfaces (`SpeechSynthesizer`, `SpeechRecognizer`,
  `RealtimeSpeechRecognizer`, `RealtimeSpeechSynthesizer`,
  `VoiceSessionProvider`) and `voice.Pipeline` architecture notes.
- **`docs/DEVELOPMENT.md`**: Added `providers/elevenlabs/`, `voice/`,
  `ELEVENLABS_API_KEY` / `ELEVENLABS_AGENT_ID`, example commands, and provider
  registry listing.
- **`docs/SECURITY.md`**: Added Voice and Speech Privacy & Auth Controls
  (redaction, Speech Engine JWT verification, opt-in consent-gated cloning).
- **`examples/README.md`**: Documented all new speech and voice examples and
  prerequisites.
