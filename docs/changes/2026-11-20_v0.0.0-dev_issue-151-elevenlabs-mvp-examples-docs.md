## Summary

Adds runnable ElevenLabs MVP examples (synchronous TTS, HTTP streaming TTS, and
file-based Scribe transcription) with unit tests, plus comprehensive user
documentation covering environment configuration, capability discovery,
verified models, unsupported models/formats/limits, and privacy/reliability
defaults for Issue #151 (`IRIS-VOICE-008`).

## Motivation

Completes the P0 ElevenLabs MVP deliverable by giving developers copy-pasteable,
runnable CLI programs and clear documentation of what is supported, what fails
fast before HTTP, and what remains deferred to P1/P2 issues.

## What Changed

### New Additions

- **`examples/speech/elevenlabs-synthesize/main.go`** & **`main_test.go`**:
  Runnable synchronous TTS CLI (`-text`, `-voice`, `-model`, `-out`) writing
  MP3 output to disk and reporting metadata only, plus unit tests covering
  success, validation failure, and cancellation.
- **`examples/speech/elevenlabs-stream/main.go`** & **`main_test.go`**:
  Runnable HTTP streaming TTS CLI writing incremental audio chunks directly to
  disk and reporting first-chunk latency, chunk count, total bytes, and final
  metadata, plus unit tests covering success, HTTP error, and mid-stream
  cancellation.
- **`examples/speech/elevenlabs-transcribe/main.go`** & **`main_test.go`**:
  Runnable file/reader Scribe transcription CLI (`-file`, `-model`, `-language`,
  `-diarize`, `-timestamps`, `-events`), plus unit tests covering success,
  missing file error, and cancellation.
- **`docs/guides/speech.md`**: Dedicated Speech & Audio guide covering env
  configuration (`ELEVENLABS_API_KEY`, `ELEVENLABS_VOICE_ID`), capability
  discovery, verified models, supported TTS formats, Scribe limits,
  unsupported models/formats/features, privacy/reliability defaults, and live
  integration test invocation.

### Modifications

- **`docs/PROVIDERS.md`**: Added ElevenLabs to the Feature Support Matrix,
  Supported Providers table, Provider Details (`### ElevenLabs`), Choosing a
  Provider table, and Rate Limits and Pricing section.
- **`docs/README.md`**: Linked `docs/guides/speech.md` in the Guides table.
- **`examples/README.md`**: Added `ELEVENLABS_API_KEY` prerequisite,
  `examples/speech/...` run commands, and Highlights entries.

## Usage Examples

### Example: End-to-End Synthesize, Stream, and Transcribe

```bash
export ELEVENLABS_API_KEY="your-key"
go run ./examples/speech/elevenlabs-synthesize -text "Hello from Iris." -out /tmp/iris-speech.mp3
go run ./examples/speech/elevenlabs-stream -text "Streaming from Iris." -out /tmp/iris-stream.mp3
go run ./examples/speech/elevenlabs-transcribe -file /tmp/iris-speech.mp3 -diarize -timestamps word
```
