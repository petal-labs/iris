## Summary

Adds the provider-agnostic `core.RealtimeSpeechSynthesizer` /
`core.RealtimeSynthesisSession` incremental-input TTS contract in `core` and
implements ElevenLabs' incremental-input WebSocket TTS endpoint
(`wss://api.elevenlabs.io/v1/text-to-speech/{voice_id}/stream-input`) in
`providers/elevenlabs` for Issue #154 (`IRIS-VOICE-011`).

## Motivation

Streaming LLM-to-voice pipelines need to push partial text tokens into speech
synthesis as soon as they arrive, force generation on turn/sentence boundaries
(`Flush`) without reopening the socket, gracefully drain trailing audio at
end-of-input (`Finish`), and immediately abort playback on barge-in (`Close` /
context cancellation) while enforcing model compatibility so unsupported models
such as `eleven_v3` fail fast with clear errors instead of opaque WebSocket
handshakes.

## What Changed

### New Additions

- **`core/speech.go`**:
  - Added `FeatureSpeechSynthesisRealtime` (`"speech_synthesis_realtime"`).
- **`core/speech_realtime.go`** & **`core/speech_realtime_test.go`**:
  - Added `RealtimeSynthesisConfig` (with `Validate()`, `String()`, `GoString()`),
    `RealtimeSynthesisSession` (`SendText`, `Flush`, `Finish`, `Audio`, `Err`,
    `Close`), `RealtimeSpeechSynthesizer`, `AsRealtimeSpeechSynthesizer`, and
    `(*Client).StartRealtimeSynthesis`.
- **`providers/elevenlabs/tts_ws.go`** & **`tts_ws_test.go`**:
  - Added `DefaultRealtimeTTSModel` (`ModelElevenFlashV25`) and
    `DefaultRealtimeTTSBufferSize` (`32`).
  - Implemented `(*ElevenLabs).StartRealtimeSynthesis(ctx, cfg)`:
    - Enforces model compatibility before dialing: rejects known catalog models
      without `core.FeatureSpeechSynthesisRealtime` (including `ModelElevenV3`
      and Scribe STT models) as well as `eleven_v3*`, `eleven_v4*`, and
      `scribe*` model IDs with `*core.ProviderError` wrapping
      `core.ErrNotSupported` (`Code: "unsupported_model"`).
    - Validates output audio format, `ChunkLengthSchedule` bounds (`[50, 500]`),
      and `InactivityTimeout` bounds (`[1s, 180s]`).
    - Reuses internal `dialWebSocket` (`xi-api-key` HTTP upgrade auth header)
      and immediately transmits the BOS initialization frame (`{"text":" "}`
      plus optional `voice_settings` and `generation_config`), closing the
      socket on BOS failure.
    - Serializes incremental text writes (`SendText`, rejecting `""` to prevent
      accidental EOS), mid-session `Flush` (`{"text":" ","flush":true}` keeping
      the connection open across turns), and graceful `Finish` (`{"text":""}`
      EOS).
    - Streams decoded base64 audio chunks on bounded `Audio()` with monotonic
      `Sequence` and `IsFinal` propagation, maps server error frames to typed
      `*core.ProviderError` with API key scrubbing, and guarantees prompt
      socket/goroutine cleanup on `Close()` or context cancellation even when
      `Audio()` is full.
- **`tests/integration/elevenlabs_test.go`**:
  - Added optional credentialed `TestElevenLabs_RealtimeTTS` covering preflight
    `eleven_v3` rejection and live multi-turn `SendText` -> `Flush` ->
    `SendText` -> `Finish` audio streaming.

### Modifications

- **`providers/elevenlabs/models.go`**, **`provider.go`**, **`provider_test.go`**:
  - Advertised `core.FeatureSpeechSynthesisRealtime` on `ModelElevenFlashV25`
    and `ModelElevenMultilingualV2` (explicitly excluding `ModelElevenV3` and
    Scribe models) and in `(*ElevenLabs).Supports`.
- **`core/doc.go`**, **`providers/elevenlabs/doc.go`**, **`docs/guides/speech.md`**, **`docs/PROVIDERS.md`**:
  - Documented the incremental-input WebSocket TTS API, model compatibility
    matrix, preflight bounds, and cleanup contract.

## API & Behavior

```go
sess, err := client.StartRealtimeSynthesis(ctx, core.RealtimeSynthesisConfig{
	Model:   elevenlabs.ModelElevenFlashV25,
	VoiceID: "JBFqnCBsd6RMkjVDRZzb",
	Format:  core.AudioFormatPCM16000,
})
if err != nil {
	return err
}
defer sess.Close()

_ = sess.SendText(ctx, "Hello from ")
_ = sess.SendText(ctx, "Iris. ")
_ = sess.Flush(ctx)
_ = sess.SendText(ctx, "Streaming complete.")
_ = sess.Finish(ctx)

for chunk := range sess.Audio() {
	// Play chunk.Data
}
if err := <-sess.Err(); err != nil {
	return err
}
```

## Integration Notes

- Unblocks Issue `#156` (`IRIS-VOICE-013`: Iris-managed voice pipeline) by
  providing provider-agnostic incremental LLM-to-TTS streaming with explicit
  `Flush`, `Finish`, and instant `Close` for barge-in cancellation.
- Reuses `providers/elevenlabs/ws.go` without introducing additional third-party
  dependencies.

## Breaking Changes & Migration

None. Existing providers compile and pass tests unchanged.

## Deferred / Out of Scope

- Text-to-Dialogue WebSocket API (`/v1/text-to-dialogue/stream-input`) required
  for `eleven_v3` multi-voice dialogue streaming — out of scope for
  `/v1/text-to-speech/{voice_id}/stream-input`.
- Character alignment payload surfacing (`normalizedAlignment` / `alignment`)
  in `core.AudioChunk` — `SyncAlignment` query flag is wired; structured
  alignment events can be layered if needed by downstream UIs.
- Full-duplex voice session API and pipeline orchestration — deferred to Issues
  `#155`–`#156`.
