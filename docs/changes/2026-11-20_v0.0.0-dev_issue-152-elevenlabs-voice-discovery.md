## Summary

Adds read-only ElevenLabs voice discovery, cursor pagination, metadata retrieval,
and voice settings inspection (`ListVoices`, `ListAllVoices`, `GetVoice`,
`GetVoiceSettings`, `GetDefaultVoiceSettings`) to `providers/elevenlabs` for
Issue #152 (`IRIS-VOICE-009`). Voice creation, editing, deletion, and cloning
are explicitly excluded.

## Motivation

Applications and downstream PetalFlow voice nodes need to discover available
ElevenLabs voices, filter by search/category/type, paginate reliably, and read
default or per-voice synthesis settings (`core.VoiceSettings`) without exposing
unintended voice mutation or cloning capabilities.

## What Changed

### New Additions

- **`providers/elevenlabs/voices.go`**:
  - `MaxVoicesPageSize = 100`.
  - `Voice` struct capturing `VoiceID`, `Name`, `Category`, `Description`,
    `PreviewURL`, `Labels`, `AvailableForTiers`, `*core.VoiceSettings`,
    `IsOwner`, `IsLegacy`, `IsMixed`.
  - `VoiceListRequest` (with `Validate()` checking `PageSize` in `0..100` and
    `SortDirection` in `""`/`"asc"`/`"desc"`) and `VoiceListResponse`.
  - `(*ElevenLabs).ListVoices(ctx, req)` (`GET /v2/voices` with cursor
    pagination and filters).
  - `(*ElevenLabs).ListAllVoices(ctx, req)` (automatic cursor pagination with
    caller-request immutability, duplicate `next_page_token` cycle detection,
    bounded page cap, and inter-page cancellation checks).
  - `(*ElevenLabs).GetVoice(ctx, voiceID)` (`GET /v1/voices/{voice_id}`).
  - `(*ElevenLabs).GetDefaultVoiceSettings(ctx)` (`GET /v1/voices/settings/default`).
  - `(*ElevenLabs).GetVoiceSettings(ctx, voiceID)` (`GET /v1/voices/{voice_id}/settings`).
- **`providers/elevenlabs/voices_test.go`**: Race-tested unit tests covering
  query parameter encoding, nil/invalid requests, 3-page pagination without
  mutating caller request, duplicate-token cycle protection, inter-page
  cancellation, voice ID path escaping, blank voice ID preflight rejection,
  HTTP errors, JSON decode errors, and timeouts.

### Modifications

- **`tests/integration/elevenlabs_test.go`**: Added
  `TestElevenLabs_VoiceDiscovery_And_Settings` validating `ListVoices`,
  `GetVoice`, `GetVoiceSettings`, and `GetDefaultVoiceSettings` live against

- **`providers/elevenlabs/doc.go`**, **`docs/guides/speech.md`**,
  **`docs/PROVIDERS.md`**: Documented read-only voice discovery/settings APIs

## Technical Specification

### Data Schemas / Types

```go
const MaxVoicesPageSize = 100

type Voice struct {
	VoiceID           string              `json:"voice_id"`
	Name              string              `json:"name"`
	Category          string              `json:"category,omitempty"`
	Description       string              `json:"description,omitempty"`
	PreviewURL        string              `json:"preview_url,omitempty"`
	Labels            map[string]string   `json:"labels,omitempty"`
	AvailableForTiers []string            `json:"available_for_tiers,omitempty"`
	Settings          *core.VoiceSettings `json:"settings,omitempty"`
	IsOwner           bool                `json:"is_owner,omitempty"`
	IsLegacy          bool                `json:"is_legacy,omitempty"`
	IsMixed           bool                `json:"is_mixed,omitempty"`
}

type VoiceListRequest struct {
	NextPageToken     string
	PageSize          int
	Search            string
	Sort              string
	SortDirection     string
	VoiceType         string
	Category          string
	IncludeTotalCount *bool
}

type VoiceListResponse struct {
	Voices        []Voice `json:"voices"`
	HasMore       bool    `json:"has_more"`
	NextPageToken string  `json:"next_page_token,omitempty"`
	TotalCount    int     `json:"total_count,omitempty"`
}
```

## Usage Examples

### Example: Discovering Voices and Reusing Settings for Synthesis

```go
page, err := provider.ListVoices(ctx, &elevenlabs.VoiceListRequest{
	PageSize: 10,
	Category: "premade",
})
if err != nil {
	return err
}
settings, err := provider.GetVoiceSettings(ctx, page.Voices[0].VoiceID)
if err != nil {
	return err
}
resp, err := client.Synthesize(ctx, &core.SpeechRequest{
	Model:         elevenlabs.ModelElevenFlashV25,
	VoiceID:       page.Voices[0].VoiceID,
	Text:          "Hello with discovered voice settings.",
	VoiceSettings: settings,
})
```

### Example: Invalid Pagination Bounds (Error Case)

```go
_, err := provider.ListVoices(ctx, &elevenlabs.VoiceListRequest{PageSize: 200})
// errors.Is(err, core.ErrBadRequest) == true (rejected before HTTP)
```
