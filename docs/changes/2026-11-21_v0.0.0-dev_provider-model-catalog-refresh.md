## Summary

Syncs Iris's static provider model catalogs against `https://models.dev/api.json?type=all` as of 2026-11-21. Adds new active flagships across OpenAI (`gpt-6.2-astra`, `gpt-6.2-sol`, `gpt-6.1-terra`), Anthropic (`claude-fable-5-2`), Google Gemini (`gemini-4-neon`, `gemini-4-hydrogen`, `gemini-4-carbon`), and Azure AI Foundry (`gpt-6.2-astra`, `gpt-6.2-sol`, `gpt-6.1-terra`, `claude-fable-5-2`), and removes models that are either absent from models.dev or marked `status: "deprecated"` across OpenAI, Anthropic, Gemini, and xAI.

Perplexity's four Sonar models (`sonar`, `sonar-pro`, `sonar-reasoning-pro`, `sonar-deep-research`) are marked `deprecated` in models.dev with no non-deprecated replacement Sonar models listed for `/chat/completions`; Iris retains them and documents their upstream deprecation status. README files, provider guides, `iris init` defaults, runnable examples, and tests have been updated to match the refreshed catalogs.

## Motivation

Iris's static provider catalogs drive model discovery (`Provider.Models()`), capability queries (`GetModelInfo`, `HasCapability`), and OpenAI's Responses vs. Chat Completions endpoint routing. Keeping the catalogs synchronized with models.dev ensures new flagships route and advertise capabilities accurately while deprecated or retired IDs are removed rather than silently failing upstream.

## Usage Examples

### Example: Using the new OpenAI and Gemini flagships

```go
package main

import (
	"context"
	"fmt"
	"os"

	"github.com/petal-labs/iris/core"
	"github.com/petal-labs/iris/providers/gemini"
	"github.com/petal-labs/iris/providers/openai"
)

func main() {
	ctx := context.Background()

	oai := core.NewClient(openai.New(os.Getenv("OPENAI_API_KEY")))
	resp, err := oai.Chat(openai.ModelGPT62Astra).
		User("Summarize Go generics in two sentences.").
		GetResponse(ctx)
	if err != nil {
		fmt.Fprintln(os.Stderr, "OpenAI error:", err)
		os.Exit(1)
	}
	fmt.Println(resp.Output)

	gem := core.NewClient(gemini.New(os.Getenv("GEMINI_API_KEY")))
	resp, err = gem.Chat(gemini.ModelGemini4Neon).
		ReasoningEffort(core.ReasoningEffortHigh).
		User("Explain how thinkingLevel works in Gemini 4.").
		GetResponse(ctx)
	if err != nil {
		fmt.Fprintln(os.Stderr, "Gemini error:", err)
		os.Exit(1)
	}
	fmt.Println(resp.Output)
}
```

## Integration Notes

- **OpenAI routing:** `ModelGPT62Astra`, `ModelGPT62Sol`, and `ModelGPT61Terra` explicitly set `APIEndpoint: core.APIEndpointResponses`, verified by `TestShouldUseResponsesAPI` and `TestNewGPT6Models`.
- **Gemini reasoning control:** `usesThinkingLevel` matches `gemini-3` and `gemini-4` prefixes, covering `gemini-4-carbon`, `gemini-4-hydrogen`, and `gemini-4-neon`, verified by `TestUsesThinkingLevel`.
- **Unchanged providers:** Z.ai already matched models.dev 18-for-18; Ollama discovers models dynamically at runtime; Hugging Face routes arbitrary hub IDs; Voyage AI and ElevenLabs are not cataloged in models.dev.

## Breaking Changes & Migration

Callers referencing removed `core.ModelID` constants will fail to compile and should migrate as follows:

- OpenAI image models (`ModelGPTImage1`, `ModelGPTImage15`, `ModelGPTImage1Mini`, `ModelChatGPTImageLatest`) → `openai.ModelGPTImage2`
- OpenAI legacy chat models (`ModelGPT35Turbo`, `ModelGPT4`, `ModelGPT4Turbo`) → `openai.ModelGPT4o` / `openai.ModelGPT4oMini` (Chat Completions) or `openai.ModelGPT62Astra` / `openai.ModelGPT54Mini` (Responses)
- OpenAI `ModelGPT41Nano` → `openai.ModelGPT41Mini` or `openai.ModelGPT54Nano`
- OpenAI reasoning (`ModelO1`, `ModelO1Pro`, `ModelO3Mini`, `ModelO4Mini`) → `openai.ModelO3` / `openai.ModelO3Pro` or `openai.ModelGPT62Astra`
- Anthropic `ModelClaudeSonnet45` / `ModelClaudeSonnet45Thinking` → `anthropic.ModelClaudeSonnet55` / `anthropic.ModelClaudeSonnet55Thinking` (or `ModelClaudeSonnet46`)
- Gemini preview/deprecated image models (`ModelGemini3ProImage`, `ModelGemini31FlashImagePreview`, `ModelGemini25FlashImage`) → `gemini.ModelGemini3ProImageStable`, `gemini.ModelGemini31FlashImage`, or `gemini.ModelGemini31FlashLiteImage`
- xAI `ModelGrokBuild01` → `xai.ModelGrok47`

## Deferred / Out of Scope

- Dated model snapshots (`gpt-4o-2024-*`, `claude-*-2025*`), audio/TTS/video/realtime models (`gpt-realtime-2.1`, `gemini-*-tts*`, `gemini-*-live*`, `lyria-*`, `grok-imagine-*`), OpenAI embedding IDs (`text-embedding-*`), open-weight Gemma entries, and research/computer-use preview IDs remain intentionally excluded per Iris catalog curation policy.
- Perplexity Sonar replacements are deferred until Perplexity publishes non-deprecated models for `/chat/completions` (Perplexity Agent API uses a separate multi-provider router schema).
