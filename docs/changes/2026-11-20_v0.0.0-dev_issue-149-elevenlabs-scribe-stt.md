## Summary

Implements file and reader-backed speech-to-text transcription
(`(*ElevenLabs).Transcribe`) via ElevenLabs' Scribe API
(`POST /v1/speech-to-text`) for Issue #149 (`IRIS-VOICE-006`). Supports in-memory
`core.AudioData` and streaming `io.Reader` multipart uploads, language detection,
word/character timestamps, speaker diarization, audio event tagging, keyterms,
and preflight limit validation, and enables `core.FeatureSpeechRecognition` on
`ElevenLabs` and its Scribe models (`scribe_v1`, `scribe_v2`).

## Motivation

File-based Scribe transcription completes the core speech-to-text capability for
the ElevenLabs MVP release, unblocking PetalFlow transcription nodes (`#249`),
Cortex committed-transcript ingestion (`#76`, `#78`, `#79`), and MVP reliability
and example suites (`#150`, `#151`).

## What Changed

### New Additions

- **`providers/elevenlabs/stt.go`**:
  - Constants: `DefaultSTTModel = ModelScribeV2`,
    `DefaultMaxTranscriptionBytes = 100 * 1024 * 1024` (100 MiB),
    `MaxScribeKeyterms = 1000`, `MaxScribeSpeakers = 32`,
    `MaxScribeTemperature = 2.0`.
  - `(*ElevenLabs).Transcribe(ctx, req)` implementing `core.SpeechRecognizer`:
    - Validates `req`, enforces ElevenLabs Scribe limits before HTTP (keyterms
      count <= 1000 and rejected on `scribe_v1`, `num_speakers <= 32`,
      `temperature <= 2.0`, timestamp granularity `none`/`word`/`character` with
      `segment` rejected, raw PCM restricted to 16000Hz mono `pcm_s16le_16`),
      and fails fast on empty API keys or empty readers before opening HTTP.
    - Streams `multipart/form-data` uploads through an `io.Pipe` with bounded
      size enforcement (`req.MaxBytes` or `DefaultMaxTranscriptionBytes`) and
      guaranteed writer goroutine cleanup on cancellation or early server error.
    - Maps Scribe JSON responses (`transcription_id`, `language_code`,
      `language_probability`, `text`, `words[]`, `audio_events[]`) into
      `*core.TranscriptionResponse` with `IsFinal = true`, derived `Duration`,
      and `Usage` (`InputBytes`, `AudioDuration`).
- **`providers/elevenlabs/stt_test.go`**: Race-tested unit tests verifying
  multipart form encoding, full `AudioData` + `core.Client.Transcribe` round-trip,
  `io.Reader` + PCM `pcm_s16le_16` + filename derivation, all Scribe limit
  rejections before HTTP, oversized streaming reader cutoff, typed HTTP errors,
  JSON decode errors, and cancellation/timeout goroutine cleanup.

### Modifications

- **`providers/elevenlabs/models.go`**: Added `core.FeatureSpeechRecognition` to

- **`providers/elevenlabs/provider.go`**: Updated `Supports()` to return `true`

## Technical Specification

### Data Schemas / Types

```go
const (
	DefaultSTTModel                    = ModelScribeV2
	DefaultMaxTranscriptionBytes int64 = 100 * 1024 * 1024
	MaxScribeKeyterms                  = 1000
	MaxScribeSpeakers                  = 32
	MaxScribeTemperature               = 2.0
)
```

### API Endpoints

- `POST {BaseURL}/v1/speech-to-text`
  - Headers: `xi-api-key`, `Content-Type: multipart/form-data; boundary=...`
  - Form fields: `model_id`, `file`, optional `language_code`, `diarize`,
    `num_speakers`, `timestamps_granularity`, `tag_audio_events`, `temperature`,
    `file_format` (`pcm_s16le_16` for raw PCM), repeated `keyterms`
  - Response: JSON containing `transcription_id`, `language_code`,
    `language_probability`, `text`, `words[]`, `audio_events[]`
  - Errors: normalized via `normalizeError` (`400`/`422` -> `ErrBadRequest`,
    `401`/`403` -> `ErrUnauthorized`, `404` -> `ErrNotFound`,
    `429` -> `ErrRateLimited`, `5xx` -> `ErrServer`).

## Usage Examples

### Example: Transcribing an Audio File via `core.Client`

```go
f, err := os.Open("meeting.mp3")
if err != nil {
	return err
}
defer f.Close()

client := core.NewClient(provider)
resp, err := client.Transcribe(ctx, &core.TranscriptionRequest{
	Model:          elevenlabs.ModelScribeV2,
	Reader:         f,
	Filename:       "meeting.mp3",
	Diarize:        true,
	Timestamps:     core.TimestampGranularityWord,
	TagAudioEvents: true,
	Keyterms:       []string{"Iris", "PetalFlow"},
})
if err != nil {
	return err
}
// resp.IsFinal == true; resp.Text, resp.Language, resp.Words, resp.AudioEvents populated
```

### Example: Preflight Limit Validation (Error Case)

```go
_, err := client.Transcribe(ctx, &core.TranscriptionRequest{
	Model:    elevenlabs.ModelScribeV1,
	Audio:    &core.AudioData{Data: mp3Bytes, Format: core.AudioFormatMP3_44100_128},
	Keyterms: []string{"Iris"},
})
// errors.Is(err, core.ErrInvalidTranscriptionRequest) == true (scribe_v1 does not support keyterms)
```
