## Summary

Implements synchronous ElevenLabs text-to-speech synthesis (`(*ElevenLabs).Synthesize`)
via `POST /v1/text-to-speech/{voice_id}` for Issue #147 (`IRIS-VOICE-004`). Adds
provider-agnostic `core.AudioFormat` to ElevenLabs `output_format` mapping,
response metadata extraction (`request-id`, `character-cost`, `Content-Type`),
and enables `core.FeatureSpeechSynthesis` on `ElevenLabs` and its verified TTS
models (`eleven_multilingual_v2`, `eleven_flash_v2_5`, `eleven_v3`).

## Motivation

Synchronous TTS is the first core speech capability in the ElevenLabs MVP
backlog. Implementing `core.SpeechSynthesizer.Synthesize` unlocks direct and
`core.Client.Synthesize` audio generation while establishing shared request body
and `output_format` mapping helpers for HTTP streaming TTS (`#148`).

## What Changed

### New Additions

- **`providers/elevenlabs/format.go`**:
  - `DefaultTTSFormat = core.AudioFormatMP3_44100_128`.
  - `resolveOutputFormat(f core.AudioFormat)` mapping provider-agnostic formats
    to ElevenLabs `output_format` query values (`mp3_22050_32`,
    `mp3_44100_{32,64,96,128,192}`, `pcm_{8000,16000,22050,24000,44100,48000}`,
    `ulaw_8000`, `alaw_8000`, `opus_48000_{32,64,96,128,192}`) and rejecting
    unsupported codecs, sample rates, bitrates, or multi-channel (`>1`) requests
    with errors wrapping `core.ErrInvalidAudioFormat`.
  - `responseMIMEType` parsing `Content-Type` headers safely with fallback.
- **`providers/elevenlabs/tts.go`**:
  - `DefaultTTSModel = ModelElevenMultilingualV2`.
  - `(*ElevenLabs).Synthesize(ctx, req)` implementing `core.SpeechSynthesizer`:
    validates `req`, resolves output format and model, escapes `voice_id`,
    sends JSON body (`text`, `model_id`, `language_code`, `voice_settings`,
    `seed`, `previous_text`, `next_text`) to
    `POST /v1/text-to-speech/{voice_id}?output_format=...`, enforces a 100 MiB
    response read cap, rejects empty audio bodies with `core.ErrDecode`, and
    populates `SpeechResponse` metadata (`ID` from `request-id`, `Model`,
    `VoiceID`, `Audio`, `Usage.InputCharacters` from `character-cost`, and
    `Usage.OutputBytes`).
  - `(*ElevenLabs).StreamSynthesize(ctx, req)` returning `core.ErrNotSupported`
    until Issue `#148` implements HTTP streaming TTS.
- **`providers/elevenlabs/tts_test.go`**: Race-tested unit tests covering all
  format mappings/rejections, full option/header/metadata round-trips, default
  model/format behavior, `voice_id` URL escaping, preflight validation, typed
  HTTP errors, empty body / mid-transfer read failures, timeouts, and
  cancellation.

### Modifications

- **`providers/elevenlabs/models.go`**: Added `core.FeatureSpeechSynthesis` to
  `ModelElevenMultilingualV2`, `ModelElevenFlashV25`, and `ModelElevenV3`.
- **`providers/elevenlabs/provider.go`**: Updated `Supports()` to return `true`
  for `core.FeatureSpeechSynthesis`.
- **`providers/elevenlabs/doc.go`**: Documented synchronous TTS usage,
  supported output formats, response metadata, and remaining limitations.
- **`providers/elevenlabs/provider_test.go`**: Updated capability and model
  assertions to verify `FeatureSpeechSynthesis` and `core.AsSpeechSynthesizer`.

## Technical Specification

### Data Schemas / Types

```go
const DefaultTTSModel = ModelElevenMultilingualV2

var DefaultTTSFormat = core.AudioFormatMP3_44100_128
```

### API Endpoints

- `POST {BaseURL}/v1/text-to-speech/{voice_id}?output_format={format}`
  - Headers: `xi-api-key`, `Content-Type: application/json`
  - Request body: `{"text", "model_id", "language_code", "voice_settings", "seed", "previous_text", "next_text"}`
  - Response: binary audio payload + `request-id`, `character-cost`, `Content-Type` headers
  - Errors: normalized via `normalizeError` (`400`/`422` -> `ErrBadRequest`, `401`/`403` -> `ErrUnauthorized`, `404` -> `ErrNotFound`, `429` -> `ErrRateLimited`, `5xx` -> `ErrServer`).

## Usage Examples

### Example: Synchronous TTS via `core.Client`

```go
provider, err := elevenlabs.NewFromEnv()
if err != nil {
	return err
}
client := core.NewClient(provider)

resp, err := client.Synthesize(ctx, &core.SpeechRequest{
	Model:   elevenlabs.ModelElevenFlashV25,
	VoiceID: "JBFqnCBsd6RMkjVDRZzb",
	Text:    "Hello from Iris.",
	Format:  core.AudioFormatMP3_44100_128,
})
if err != nil {
	return err
}
audioBytes, err := resp.Audio.GetBytes()
```

### Example: Unsupported Format Rejection (Error Case)

```go
_, err := client.Synthesize(ctx, &core.SpeechRequest{
	VoiceID: "JBFqnCBsd6RMkjVDRZzb",
	Text:    "Hello",
	Format:  core.AudioFormatWAV16000,
})
// errors.Is(err, core.ErrInvalidAudioFormat) == true (rejected before HTTP)
```
