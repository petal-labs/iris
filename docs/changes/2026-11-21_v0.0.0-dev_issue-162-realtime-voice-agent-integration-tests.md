## Summary

Adds deterministic end-to-end real-time voice-agent integration tests, a
first-audio latency benchmark, and an optional credentialed live voice pipeline
test (`//go:build integration`) for Issue #162 (`IRIS-VOICE-019`), and fixes a
startup deadlock discovered by the integration suite in `voice.Pipeline` when
`EventBufferSize == 1` is combined with real-time STT.

## Motivation

Before unblocking downstream PetalFlow (`#254`) and Cortex (`#80`) voice
integration suites, Iris needed an end-to-end verification harness exercising
multi-turn STT → LLM → TTS conversations, barge-in interruptions and stale
audio suppression, registry middleware and external tool execution, provider
switching, failure/cancellation cleanup, telemetry privacy redaction, and
first-audio latency measurement across both offline mocked transports and
optional credentialed ElevenLabs endpoints.

## What Changed

### New Additions

- **`tests/voice_agent_integration_test.go`**:
  - `TestVoiceAgent_EndToEndMultiTurnConversationAndTranscriptOrder`: exercises
    multi-turn real-time STT (`partial` → `committed`) → streaming LLM →
    incremental WebSocket TTS with `core.VoiceTurnTracker` and
    `core.VoiceTelemetryHook`, verifying monotonic event sequences, strict
    transcript ordering, turn metrics, and zero raw audio/transcript/secret
    leakage in `VoiceEvent.String()` and telemetry records.
  - `TestVoiceAgent_InterruptionBargeInAndStaleAudioSuppression`: verifies
    mid-turn barge-in via STT partial speech cancels the in-flight LLM context,
    emits `VoiceEventTurnInterrupted`, suppresses stale audio chunks via
    `VoiceTurnTracker.ShouldPlayAudio`, and completes a clean follow-up turn.
  - `TestVoiceAgent_ToolExecutionAutoAndExternalAndInterruptMidTool`: verifies
    `*tools.Registry` middleware execution (`voice.RegistryToolExecutor`),
    missing-tool error recovery, and interrupting a turn blocked on external
    `SubmitToolResult`.
  - `TestVoiceAgent_ProviderSwitching`: runs the same voice session workflow
    across OpenAI, Anthropic, and Gemini LLM doubles paired with incremental
    WebSocket TTS and HTTP streaming TTS, and confirms distinct `SpeechEngine`
    (`http.Handler`) and `ElevenAgents` (`core.VoiceSessionProvider`) modes.
  - `TestVoiceAgent_FailureCancellationAndGoroutineCleanup`: tests mid-turn TTS
    error recovery, fatal STT disconnect error propagation on `Err()`, parent
    context cancellation with `EventBufferSize: 1`, and goroutine leak checks
    (`runtime.NumGoroutine()`).
  - `BenchmarkVoiceAgent_FirstAudioLatency`: measures first-audio latency and
    reports `first_audio_ms/op` via `b.ReportMetric` without asserting
    unsupported wall-clock SLA guarantees.
- **`tests/integration/elevenlabs_test.go`**:
  - Added `TestElevenLabs_LiveVoicePipeline` (`//go:build integration`,
    gated on `ELEVENLABS_API_KEY`): synthesizes a spoken PCM 16kHz prompt,
    streams 8 KiB audio chunks through `voice.Pipeline` backed by real
    ElevenLabs Scribe v2 Realtime WebSocket STT, a streaming echo LLM, and real
    ElevenLabs Flash v2.5 Incremental WebSocket TTS, asserting committed
    transcription, non-empty synthesized audio output, and measured
    `first_audio_latency` without logging audio, transcripts, or keys.

### Modifications

- **`tests/provider_api_conformance_test.go`**:
  - Added `elevenlabs` to `providerAPISurfaces` so `TestProviderAPISurfaceConformance`
    validates ElevenLabs' standard constructor/option signatures alongside all
    other registered providers.
- **`voice/pipeline.go`**:
  - Fixed a startup deadlock in `(*Pipeline).StartVoiceSession` uncovered by
    `TestVoiceAgent_FailureCancellationAndGoroutineCleanup`: previously, when
    both `STT != nil` and `EventBufferSize == 1`, `StartVoiceSession` emitted
    two synchronous events (`VoiceEventSessionStarted` +
    `VoiceEventSessionState`) into a 1-slot buffer before returning the session
    to the caller. `StartVoiceSession` now initializes `s.setState(s.idleState())`
    and emits a single `VoiceEventSessionStarted` carrying that initial state.
- **`docs/guides/speech.md`** & **`docs/guides/petalflow-voice-integration.md`**:
  - Documented commands for running the offline voice-agent integration suite,
    first-audio latency benchmark, and live pipeline test; updated the
    cross-repository dependency matrix (`petalflow#254` and `cortex#80`
    unblocked) and noted benchmark vs. SLA semantics.

## API & Behavior

```bash
# Offline real-time voice-agent integration tests (CI-safe, no credentials)
go test -race -count=1 -v ./tests -run TestVoiceAgent

# First-audio latency benchmark
go test -bench=BenchmarkVoiceAgent_FirstAudioLatency -benchmem -run "^$" ./tests

# Optional live ElevenLabs voice pipeline test (requires ELEVENLABS_API_KEY)
go test -count=1 -tags=integration -v ./tests/integration -run TestElevenLabs_LiveVoicePipeline
```
